Quick Reference

金融常用公式速查

收益率 · 风险指标 · 业务指标 — SQL 实现 + 一键复制

简单收益率
(P_t - P_{t-1}) / P_{t-1}
(unit_nav - LAG(unit_nav) OVER(ORDER BY dt)) / LAG(unit_nav) OVER(ORDER BY dt)
对数收益率
ln(P_t / P_{t-1})
LN(unit_nav / LAG(unit_nav) OVER(ORDER BY dt))
累计收益率
(P_t - P_0) / P_0
(LAST_VALUE(nav)-FIRST_VALUE(nav)) / FIRST_VALUE(nav)
年化收益率
(1+R_total)^(252/n) - 1
AVG(daily_return)*252 用于股票/基金年化
年化波动率
σ_daily × √252
STDDEV(daily_return) * SQRT(252)
夏普比率
(R_p - R_f) / σ_p
无风险利率Rf通常取3%。
见第六阶段投资分析专题
最大回撤
min((P_t-Peak)/Peak)
MAX() OVER + (running_max-nav)/running_max
VaR(95%)
收益率第5百分位
PERCENTILE_CONT(0.05) WITHIN GROUP (ORDER BY ret)
客户留存率
当月有交易 ∩ 上月有交易 / 上月有交易
用 LAG + LEFT JOIN 实现
ARPU
SUM(amount) / COUNT(DISTINCT user)
每用户平均收入
资金净流入
SUM(CASE WHEN 流入 THEN amount ELSE -amount END)
不良贷款率
逾期贷款余额 / 总贷款余额
使用 CASE WHEN 分类统计
MySQL & PostgreSQL 日期速查
-- MySQL
CURDATE()                              -- 今天
DATE_FORMAT(d, '%Y%m%d')             -- 格式化
DATE_ADD(d, INTERVAL 1 MONTH)        -- 加一个月
TIMESTAMPDIFF(DAY, d1, d2)        -- 相差天数
LAST_DAY(d)                            -- 月末

-- PostgreSQL
CURRENT_DATE
TO_CHAR(d, 'YYYYMMDD')
d + INTERVAL '1 month'
d2 - d1                                 -- 直接相减得天数
