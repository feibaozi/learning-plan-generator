# 金融衍生品及其定价 — 学习套件

包含文件：
- `financial_derivatives_pricing.html`：交互式学习方案（含 KaTeX 渲染与知识图谱）
- `financial_derivatives_examples.ipynb`：示例 Jupyter Notebook（BS, MC, CRR）
- `requirements.txt`：运行 Notebook 所需的 Python 包
- `14_week_schedule.md`：14 周学习周计划
- `assessment_and_evaluation.md`：评估与测评计划
- `additional_readings_and_next_steps.md`：额外阅读与后续路径

快速运行（在 Windows PowerShell）：

1. 创建并激活虚拟环境（可选）：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. 安装依赖：

```powershell
pip install -r requirements.txt
```

3. 启动 Jupyter：

```powershell
jupyter notebook financial_derivatives_examples.ipynb
```

4. 在浏览器打开 `financial_derivatives_pricing.html` 以查看交互式方案。
