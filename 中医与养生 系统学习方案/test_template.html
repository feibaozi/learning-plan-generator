Hero 标题与标签测试 ⏱️ ~1分钟

测试渐变标题、标签展示、响应式字体大小

渐变标题效果：标题使用了 CSS 渐变背景和文字裁剪，在深色和浅色主题下都应该清晰可见。

标签云：标签使用圆角设计，带有边框发光效果，hover 时应有适当的过渡动画。

响应式测试：在手机端（≤768px）标题应缩小到 1.6rem，标签应自动换行。

Hero 区域是页面的视觉焦点，需要确保在所有屏幕尺寸下都有良好的显示效果。

Meta 元信息卡片测试 ⏱️ ~1分钟

测试统计数据展示、卡片阴影、hover 效果

Meta 卡片使用 flex 布局，在大屏上水平排列，在小屏上自动换行。卡片应带有适当的阴影效果，与背景形成层次感。

测试要点：

  • 数字使用强调色突出显示
  • 标签使用大写字母和间距
  • 卡片居中显示，最大宽度 700px
Meta 卡片提供快速的内容概览，数字使用强调色突出显示。

Callout 提示框组件测试 ⏱️ ~1分钟

测试 Info、Warning、Tip 三种提示框样式
💡 Info 提示：这是信息类提示框，使用绿色左侧边框，适合展示说明性内容。
⚠️ Warning 警告：这是警告类提示框，使用金色左侧边框，适合展示需要注意的内容。
💬 Tip 提示：这是提示类提示框，使用紫色左侧边框，适合展示建议性内容。
三种 callout 类型通过边框颜色区分，便于用户快速识别信息类型。

Validation 验证检查清单 ⏱️ ~1分钟

检查所有样式是否正确渲染的验证清单
📋 布局验证：
  • 内容区域宽度使用 calc(100% - 280px)
  • 容器最大宽度使用 calc(100% - 48px)
  • 侧边栏固定 280px 宽度
  • 响应式断点：1024px 和 768px
🔧 交互验证：
  • 主题切换：6种主题都应正常工作
  • 搜索功能：Ctrl+K 打开搜索
  • 图表：window.resize 响应
  • 进度条：滚动时更新
⚠️ 常见问题检查：
  • 无固定宽度导致的留白问题
  • 主题切换时颜色未更新
  • 图表未监听 resize 事件
  • 滚动时侧边栏导航未高亮
使用此清单验证模板生成的 HTML 页面是否符合规范。
