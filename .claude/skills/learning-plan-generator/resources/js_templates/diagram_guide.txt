// SVG Diagram Generation Guide (v2.1)
// 来源: SKILL.md Phase 4D IX5 + plan_params ux_interaction_config
//
// 使用规则:
// 1. 当 profile.math_density >= 0.40 时, 至少 50% KP 需含 diagram
// 2. 当 profile.math_density >= 0.70 时, 至少 80% KP 需含 diagram
// 3. G1/G5纹理: 核心公式推导类KP必须配图
// 4. G2/G6纹理: 全部KP必须配图
// ============================================================

// ============================================================
// Diagram 设计规范:
// ============================================================
//
// a) viewBox 统一: "0 0 420 150"   (宽度420, 高度150, 所有图一致)
// b) 颜色体系: 使用CSS变量对应的十六进制色值
//    - var(--accent-blue)   → #4fc3f7  (蓝色, 主路径/箭头)
//    - var(--accent-green)  → #66bb6a  (绿色, 正确/成功)
//    - var(--accent-orange) → #ffa726  (橙色, 警告/中间态)
//    - var(--accent-purple) → #ab47bc  (紫色, 变换/映射)
//    - var(--accent-red)    → #ef5350  (红色, 错误/危险)
//    - var(--accent-cyan)   → #26c6da  (青色, 决策/边界)
//    - var(--text-muted)    → #6080a8  (灰色, 网格/辅助线)
//    - var(--text-secondary)→ #a0b8d8  (浅灰, 标签文字)
// c) 必须包含三层结构:
//    - 标题区: <text> 左上方加粗标签
//    - 主视觉区: 图形+箭头+数据点
//    - 底部总结: <text> 居底一行概括
// d) SVG 属性: 内联, 无外部引用, xmlns="http://www.w3.org/2000/svg"
// e) 禁止使用: JavaScript/动画/CSS class/外部字体
//
// ============================================================
// Diagram 类型模板参考:
// ============================================================
//
// [类型A] 数据流/计算图 (链式法则、反向传播)
//   → 节点: <rect rx="5" fill="rgba(c, .12)" stroke="c">
//   → 连线: <line> + <marker> 箭头
//   → 标签: <text> 在连线上方/节点内部
//
// [类型B] 函数曲线图 (Sigmoid、梯度下降、过拟合)
//   → 曲线: <path d="M... Q... T..." fill="none" stroke="c">
//   → 坐标轴: <line> + 刻度标记
//   → 标记点: <circle> 关键位置
//
// [类型C] 对比布局 (L1/L2、CNN/RNN/Transformer)
//   → 分区: <rect> 带虚线边框
//   → 标题: <text> 各分区上方
//   → 分隔: <line> 竖线分隔
//
// [类型D] 树/层次结构 (决策树、集成学习)
//   → 节点: <rect rx="6"> + 居中文字
//   → 连线: <line> 层级连接
//   → 颜色: 随层级渐变 (根→叶子)
//
// [类型E] 映射/变换图示 (SVD、核方法、OLA投影)
//   → 变换符号: <text> 大的 φ/→/=
//   → 矩阵框: <rect> + 分块颜色
//   → 箭头: <line marker-end>
//
// [类型F] 概率分布图 (贝叶斯、GLM)
//   → 分布曲线: <path> 钟形曲线
//   → 峰值标记: <circle> 或垂直虚线
//   → 重叠阴影: opacity + 半透明fill
//
// ============================================================
// 反Bug规则:
// ============================================================
//
// a) 所有 <svg> 标签必须完全包含在单行 JS 字符串中
//    (因为 diagram 字段用单引号包裹)
// b) SVG 中的属性值用双引号, JS字符串外层用单引号
// c) 禁止在 SVG 中使用 > 字符 (使用 &gt; 替代)
// d) 任何 & 字符必须转义为 &amp;
// e) 确保 viewBox 宽高比与容器匹配 (420:150 ≈ 2.8:1)
