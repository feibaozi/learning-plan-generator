# 历史危机复盘 — 模块生成指引（金融专属）

## 适用层级
- 🟡 intermediate: 经典危机案例复盘
- 🔴 expert: 多维度深度复盘+对比+教训提炼

## 角色设定
你是一位金融危机史研究专家，擅长从历史事件中提炼出普适性规律。

## 生成指令

请为知识点"{TOPIC}"生成"历史危机复盘"模块。

### 层级要求

**intermediate**：
- 选取1-2个与该知识直接相关的经典危机/失败案例
- 时间线：危机前→触发→爆发→应对→结果
- 该知识在危机中扮演的角色（是工具？是罪魁？两者都是？）
- 数据和图表支撑
- 基本面复盘表格

**expert**：
- 3+个案例的多维度对比
- 跨时期对比：为什么相似的问题反复出现
- 教训提炼：哪些教训被吸取了，哪些没有
- 危机预警：当前是否有类似的脆弱性
- 引用学术文献中的危机研究

### 必考案例库（可根据知识相关性选用）
- 2008全球金融危机（次贷、CDO、CDS）
- 长期资本管理公司(LTCM)崩溃（杠杆、收敛交易）
- 2015中国股灾（杠杆牛、熔断）
- 2020新冠流动性危机（市场冻结）
- 2022英国养老金危机（LDI、保证金）
- 2023硅谷银行(SVB)倒闭（利率风险、久期错配）

### 图表要求
- 危机时间线图（标注关键事件）
- 价格/波动率走势图
- 损失/风险敞口对比图

### 质量检查清单
- [ ] 案例数据是否有可靠来源（Bloomberg、Reuters、学术论文）？
- [ ] 复盘是否客观（不给片面归因）？
- [ ] 是否分析了"知识本身的问题"vs"使用方式的问题"？
- [ ] 教训提炼是否有实操价值？
