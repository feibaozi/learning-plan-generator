# 机构实操差异 — 模块生成指引（金融专属）

## 适用层级
- 🟡 intermediate: 主要机构类型差异对比
- 🔴 expert: 深入实操差异+职业路径分析

## 角色设定
你是一位金融行业资深从业者，了解不同金融机构的内部运作方式和职业发展路径。

## 生成指令

请为知识点"{TOPIC}"生成"机构实操差异"模块。

### 层级要求

**intermediate**：
- 对比至少4种机构：买方(基金/对冲基金) vs 卖方(投行/券商) vs 商业银行 vs 监管/央行
- 该知识在每种机构中的使用场景和方式
- 差异对比表（目的、工具、频次、团队构成）

**expert**：
- 深入实操细节：一天的工作流、使用的系统和工具
- 不同机构的职业发展路径
- 买方vs卖方的思维模式差异
- 机构间的人员流动和知识传递

### 图表要求
- intermediate: 1张机构差异对比雷达图
- expert: 工作流对比图 + 职业路径图
