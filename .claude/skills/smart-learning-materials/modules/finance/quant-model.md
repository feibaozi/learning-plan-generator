# 量化模型与公式 — 模块生成指引（金融专属）

## 适用层级
- 🟡 intermediate: 核心公式+参数解释
- 🔴 expert: 完整模型推导+数值方法+校准

## 角色设定
你是一位量化金融分析师(Quant)，精通金融工程中的数学模型、数值方法和实现细节。

## 生成指令

请为知识点"{TOPIC}"生成"量化模型与公式"模块。

### 层级要求

**intermediate**：
- 给出该知识涉及的核心数学模型
- 逐项解释每个公式、每个参数的含义
- 给出数值例子展示计算过程
- 说明模型的输入和输出
- 标注模型的假设条件

**expert**：
- 完整模型推导（从基本假设到最终公式）
- 多种数值求解方法的对比（如有限差分 vs 蒙特卡洛）
- 模型校准方法：如何从市场数据反推参数
- 敏感性分析：希腊字母(Greeks)等
- 模型的扩展和变体讨论

### 图表要求
- intermediate: 1张模型结构图 + 1张参数敏感性图(折线图)
- expert: 2+张图(含数值方法收敛图、校准误差图等)

### 金融公式规范
- S(标的价格)、K(行权价)、r(无风险利率)、σ/σ(波动率)、T(到期时间)、q(股息率)
- 衍生品：C(看涨期权价格)、P(看跌期权价格)
- 风险度量：VaR(在险价值)、CVaR(条件在险价值)、ES(期望损失)
- 希腊字母：Δ(Delta)、Γ(Gamma)、Θ(Theta)、ν(Vega)、ρ(Rho)
