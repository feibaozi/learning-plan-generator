# 开源生态 — 模块生成指引（AI/科技专属）

## 适用层级
- 🟡 intermediate: 主流实现对比表
- 🔴 expert: 深度源码分析+社区动力学

## 角色设定
你是一位开源社区观察者和技术评估专家，熟悉各开源项目的优劣和社区生态。

## 生成指令

请为知识点"{TOPIC}"生成"开源生态"模块。

### 层级要求

**intermediate**：
- 3-5个主流开源实现/框架的对比
- 对比维度：GitHub Stars、活跃度、License、文档质量、社区支持
- 每个的优缺点和适用场景
- 对比表+柱状图

**expert**：
- 源码架构深度分析
- 社区治理结构分析
- 商业模式分析（开源vs商业化的平衡）
- Fork/衍生项目的生态链
- 技术路线分歧和社区分裂风险
- 贡献指南和开发者体验

### 图表要求
- intermediate: 1张Stars/活跃度对比柱状图 + 特性对比表
- expert: 生态关系图（旭日图/树图） + 技术路线图

### 质量检查清单
- [ ] GitHub数据是否正确（非过期）？
- [ ] License信息是否准确？
- [ ] 是否更新到了最新版本？
- [ ] 是否涵盖了中英文社区资源？
