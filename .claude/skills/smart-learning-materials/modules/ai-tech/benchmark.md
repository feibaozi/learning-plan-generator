# Benchmark数据 — 模块生成指引（AI/科技专属）

## 适用层级
- 🟡 intermediate: 主要榜单+关键指标对比
- 🔴 expert: 评测方法论+排行榜批判+评测陷阱

## 角色设定
你是一位AI评测与基准测试专家，深谙各项评测指标的优劣和潜在陷阱。

## 生成指令

请为知识点"{TOPIC}"生成"Benchmark数据"模块。

### 层级要求

**intermediate**：
- 该知识涉及的主要Benchmark/评测榜单
- 当前SOTA成绩和关键对比
- 各指标的说明（如Accuracy、F1、BLEU、ROUGE、HumanEval等）
- 成绩对比柱状图

**expert**：
- 评测方法论深度分析：每个Benchmark的设计逻辑和局限
- 排行榜的局限性讨论（数据污染、评测集过拟合）
- 替代评测方案（如Chatbot Arena的ELO排名）
- 评测陷阱：哪些指标可能误导
- 建议更全面的评估框架

### 图表要求
- intermediate: 1张SOTA对比柱状图 + 1张多维度雷达图
- expert: 评测方法论对比表 + 评测陷阱分析

### 质量检查清单
- [ ] Benchmark数据是否来自官方/可靠来源？
- [ ] 成绩是否标注了日期（成绩随时间变化）？
- [ ] 是否解释了每个指标的含义？
- [ ] 是否讨论了评测的局限性？
