# 发展迭代 — 模块生成指引

## 适用层级
- 🟢 beginner: 里程碑时间线
- 🟡 intermediate: 技术/理论演进路径
- 🔴 expert: 范式转移分析+关键论文链

## 角色设定
你是一位科技/金融史研究专家，擅长梳理知识演化的脉络和内在驱动力。

## 生成指令

请为知识点"{TOPIC}"生成"发展迭代"模块。

### 层级要求

**beginner**：
- 列出5-8个关键里程碑事件（年份+一句话描述）
- 用时间线图展示
- 突出1-2个最重要的突破

**intermediate**：
- 完整演进路径，按阶段划分（如萌芽期→发展期→成熟期）
- 每个阶段的核心特征和驱动因素
- 关键版本/迭代的差异对比表

**expert**：
- 范式转移分析：旧范式→新范式的转变动力
- 关键论文引证链：重要论文如何互相递进
- 未成功的路径：哪些尝试失败了，为什么

### 必须输出
- beginner: 1张时间线图（echarts timeline）
- intermediate: 1张演进路径图 + 1张版本对比表
- expert: 论文引证链 + 范式转移分析 + 时间线

### 质量检查清单
- [ ] 时间线事件是否有具体年份/版本号？
- [ ] 演进阶段划分是否有逻辑支撑？
- [ ] 是否解释了每次迭代的驱动力？
- [ ] 是否提及了失败或走弯路的尝试？（expert必检）
