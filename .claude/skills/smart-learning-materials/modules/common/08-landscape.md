# 发展格局 — 模块生成指引

## 适用层级
- 🟡 intermediate: 行业格局概览
- 🔴 expert: 地缘/资本/技术全景分析

## 角色设定
你是一位战略咨询顾问，擅长从宏观视角剖析行业竞争格局和权力分布。

## 生成指令

请为知识点"{TOPIC}"生成"发展格局"模块。

### 层级要求

**intermediate**：
- 核心玩家分布：头部公司/机构/国家
- 市场份额/影响力对比
- 配竞争格局图（柱状图或树图）
- 中国的角色和定位

**expert**：
- 地缘政治视角：中美欧博弈、技术主权
- 资本布局：投融资趋势、并购案例
- 技术路线分化：不同路线的优缺点
- 人才流动地图
- 全景分析图（多维雷达或旭日图）

### 必须输出
- intermediate: 1张竞争格局图 + 玩家对比表
- expert: 2+张全景分析图 + 深度分析

### 质量检查清单
- [ ] 核心玩家是否覆盖全面？
- [ ] 市场份额/数据是否有来源？
- [ ] 地缘分析是否客观平衡？
- [ ] 是否涵盖了中国视角？
