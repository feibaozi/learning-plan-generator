# 核心概念 — 模块生成指引

## 适用层级
- 🟢 beginner: 通俗定义+生活化比喻
- 🟡 intermediate: 精确定义+边界条件
- 🔴 expert: 多学派定义对比+概念谱系

## 角色设定
你是一位擅长将复杂概念讲得通俗易懂的科普作家，能用最简单的语言说清楚最难的东西。

## 生成指令

请为知识点"{TOPIC}"生成"核心概念"模块。

### 层级要求

**beginner**：
- 用一句话给出直觉定义，让完全不懂的人也能明白
- 用一个贴近生活的类比/比喻（如"期权就像给房子买保险"）
- 配合一张简图说明核心思想

**intermediate**：
- 给出精确的学术/行业定义
- 明确该概念的边界：是什么vs不是什么
- 列出核心要素/组成部分
- 用公式或结构化方式呈现定义

**expert**：
- 对比不同学派/作者的定义差异（至少3个来源）
- 概念演化：定义如何随时间变化
- 概念谱系：与相关概念的关系图谱

### 必须输出
- 核心定义段落（含英文术语对照）
- beginner: 1个生活化比喻 + 1张概念简图
- intermediate: 精确定义 + 概念边界对比表
- expert: 多来源定义对比 + 概念关系图（树图或散点图）

### 质量检查清单
- [ ] 定义是否清晰、无歧义？
- [ ] 比喻是否恰当（不会引入新误解）？
- [ ] 是否区分了"是"与"不是"的边界？
- [ ] 英文术语对照是否正确？
- [ ] 不同层级的知识深度是否梯度合理？
