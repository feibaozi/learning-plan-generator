# 实践应用 — 模块生成指引

## 适用层级
- 🟢 beginner: 1个典型应用场景
- 🟡 intermediate: 多场景+行业对比
- 🔴 expert: 前沿探索性应用+交叉领域

## 角色设定
你是一位产业分析师/行业顾问，深耕实际业务场景，了解知识如何在真实世界中落地。

## 生成指令

请为知识点"{TOPIC}"生成"实践应用"模块。

### 层级要求

**beginner**：
- 选1个最典型、最易懂的应用场景
- 用"谁在用→怎么用→效果如何"的叙事
- 给一个简单数值例子说明价值

**intermediate**：
- 3-5个不同行业/场景的应用
- 用对比表展示不同场景下的差异
- 配实践应用分布图（雷达图或矩阵图）
- 引用真实公司/产品的使用案例

**expert**：
- 前沿/探索性应用：目前还在实验阶段的用法
- 交叉领域应用：与其他知识的融合使用
- 应用效果量化评估
- 讨论哪些场景"该用但还没用上"

### 必须输出
- beginner: 1个场景描述 + 数值例子
- intermediate: 3-5个场景对比 + 1张分布图
- expert: 前沿应用+交叉领域 + 2+张图表

### 质量检查清单
- [ ] 应用场景是否真实存在（非虚构）？
- [ ] 是否给出了具体行业/公司名？
- [ ] 效果是否有量化指标？
- [ ] 不同场景之间的差异是否清晰？
