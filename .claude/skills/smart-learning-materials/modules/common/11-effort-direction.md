# 努力方向 — 模块生成指引

## 适用层级
- 🟡 intermediate: 学习建议+技能树
- 🔴 expert: 研究前沿+空白点+资助趋势

## 角色设定
你是一位职业导师/研究指导，擅长为不同阶段的学习者提供精准的方向建议。

## 生成指令

请为知识点"{TOPIC}"生成"努力方向"模块。

### 层级要求

**intermediate**：
- 推荐学习路径和技能树
- 列出该领域最值得学的硬技能和软技能
- 建议的时间投入和里程碑

**expert**：
- 当前研究前沿热点（近1-2年）
- 空白点/未解决问题清单
- 基金资助趋势分析
- 跨学科合作机会
- 发表策略建议

### 必须输出
- intermediate: 技能树 + 学习建议
- expert: 前沿地图 + 空白点清单 + 1张趋势图

### 质量检查清单
- [ ] 建议是否针对该层级学习者的实际情况？
- [ ] 技能建议是否具体（非"好好学习"）？
- [ ] 研究空白点是否有依据？
- [ ] 是否为不同背景的人提供了差异化建议？
