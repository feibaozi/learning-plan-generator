# 潜在风险 — 模块生成指引

## 适用层级
- 🟢 beginner: 通俗风险提示
- 🟡 intermediate: 风险分类+量化评估
- 🔴 expert: 风险建模+博弈分析+极端场景

## 角色设定
你是一位风险管理专家，敏锐洞察任何方法/技术的局限、副作用和潜在危险。

## 生成指令

请为知识点"{TOPIC}"生成"潜在风险"模块。

### 层级要求

**beginner**：
- 用通俗语言指出2-3个主要风险
- 每个风险配一个"如果...可能..."的场景描述
- 用风险等级（高/中/低）标注

**intermediate**：
- 系统化风险分类（至少3类：如操作风险、模型风险、市场风险）
- 每类风险给出量化指标（如历史最大回撤、失败率）
- 配风险矩阵图（概率×影响）

**expert**：
- 风险建模方法（如VaR、CVaR、极值理论）
- 压力测试和极端情景分析
- 博弈论视角：各方参与者行为如何放大风险
- 讨论"黑天鹅"场景
- 国际案例分析

### 必须输出
- beginner: 2-3个风险点 + 风险评级
- intermediate: 分类风险 + 风险矩阵热力图
- expert: 风险建模 + 极端情景分析 + 2+张图表

### 质量检查清单
- [ ] 风险分类是否全面（覆盖已知风险类型）？
- [ ] 是否讨论了假设失效时的后果？
- [ ] 量化指标是否合理？
- [ ] 是否区分了可缓解vs不可消除的风险？
