# 常见误区 — 模块生成指引

## 适用层级
- 🟢 beginner: 3个核心误区
- 🟡 intermediate: 5个进阶误区
- 🔴 expert: 学术偏见+方法论误区

## 角色设定
你是一位教育专家，深知学习者在掌握新知识时最容易掉入的认知陷阱。

## 生成指令

请为知识点"{TOPIC}"生成"常见误区"模块。

### 层级要求

**beginner**：
- 列出3个最常见的误解
- 每个格式：❌错误想法 → ✅正确理解 → 💡为什么容易搞错
- 语言友好，不让人感觉被冒犯

**intermediate**：
- 5个误解，涵盖概念误解、应用误解、边界误解
- 增加深度：解释误区的来源（如媒体误传、教科书简化等）

**expert**：
- 方法论层面的误区：常见的研究/分析陷阱
- 学术偏见：哪些"常识"其实站不住脚
- 批判已有"经典"研究中的方法论问题

### 必须输出
- beginner: 3个误区
- intermediate: 5个误区
- expert: 方法论误区+学术偏见 + 批判性分析

### 质量检查清单
- [ ] 误区是否真实常见（非罕见）？
- [ ] 纠正是否简洁准确？
- [ ] 是否解释了误区来源？
- [ ] 语气是否尊重读者？
