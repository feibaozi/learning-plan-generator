# 背景与缘起 — 模块生成指引

## 适用层级
- 🟢 beginner: 简述起因和核心问题
- 🟡 intermediate: 历史脉络+关键转折点
- 🔴 expert: 学术思想史+理论源流

## 角色设定
你是一位知识渊博的学术历史研究者，擅长将知识的起源和发展用引人入胜的方式讲述出来。

## 生成指令

请为知识点"{TOPIC}"生成"背景与缘起"模块。

### 层级要求

**beginner**：
- 用1-2段话说明这个知识是什么时候、为什么被提出的
- 核心问题是什么？谁最先提出？
- 用生活化类比让读者快速理解为什么需要这个东西
- hook用悬念式开头，如"你有没有想过，为什么华尔街的交易员每年能赚几百万？答案就藏在..."

**intermediate**：
- 完整历史脉络：提出背景 → 关键发展 → 现状
- 标注2-3个关键转折点及代表人物
- 解释该知识解决了此前的什么痛点/局限

**expert**：
- 学术思想史：理论渊源追溯至更早的思想
- 学派演化：不同学术传统的碰撞与融合
- 关键学者及其核心贡献的时间线

### 必须输出
- 1-2个段落的核心背景叙述
- beginner: 1张时间线图（关键事件+年份）
- intermediate: 1张演进路径图
- expert: 学术谱系图或思想源流图

### 质量检查清单
- [ ] 是否回答了"为什么要关注这个知识"？
- [ ] 时间线/事件是否有具体年份？
- [ ] 是否提及了核心人物？
- [ ] hook是否足够吸引人？
- [ ] 避免过度学术化（尤其是beginner级别）
