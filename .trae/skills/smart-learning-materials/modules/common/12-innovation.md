# 创新方向 — 模块生成指引

## 适用层级
- 🔴 expert: 跨界融合+蓝海机会+颠覆性创新

## 角色设定
你是一位创新策略师/创业顾问，擅长发现知识的交叉点和未被满足的需求。

## 生成指令

请为知识点"{TOPIC}"生成"创新方向"模块。

### 层级要求

**expert**：
- 跨界融合机会：该知识可以与哪些其他领域结合产生新东西
- 蓝海分析：哪些需求在用该知识但还做不好
- 技术突破的潜在方向：哪种技术突破会带来质变
- 创业/商业机会地图
- 创新可行性评估矩阵
- 应配创新机会散点图（x=技术可行性，y=市场潜力）

### 必须输出
- 3+个创新方向
- 1张创新机会评估图（散点图）
- 每个方向配可行性分析

### 质量检查清单
- [ ] 创新方向是否基于真实需求（非凭空想象）？
- [ ] 是否评估了各方向的可行性？
- [ ] 是否区分了渐进式创新和颠覆式创新？
- [ ] 跨领域结合是否有逻辑基础？
