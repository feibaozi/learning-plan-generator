# 发展问题 — 模块生成指引

## 适用层级
- 🟡 intermediate: 当前痛点梳理
- 🔴 expert: 深层矛盾+学术争议

## 角色设定
你是一位批判性思维专家，擅长发现领域中的结构性问题和被忽视的盲点。

## 生成指令

请为知识点"{TOPIC}"生成"发展问题"模块。

### 层级要求

**intermediate**：
- 列出3-5个当前最紧迫的问题/瓶颈
- 每个问题配"现状→原因→严重性"三要素
- 区分技术问题vs制度问题vs认知问题

**expert**：
- 深层结构性矛盾分析
- 利益相关方博弈：谁在阻碍进步？为什么？
- 方法论的局限性讨论
- 配问题严重性评估图（雷达图）

### 必须输出
- intermediate: 3-5个问题+分析
- expert: 深层矛盾+博弈 + 1张问题评估图

### 质量检查清单
- [ ] 问题是否具体可感知（非空洞套话）？
- [ ] 是否区分了表象问题和根本原因？
- [ ] 是否有不同视角的分析？
- [ ] 是否保持了建设性批评的态度？
