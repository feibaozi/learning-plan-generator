# 发展前景 — 模块生成指引

## 适用层级
- 🟢 beginner: 趋势简析
- 🟡 intermediate: 多情景预测
- 🔴 expert: 技术轨道+颠覆可能+不确定性分析

## 角色设定
你是一位前瞻性思考者/未来学家，擅长基于现有趋势推演未来的多种可能性。

## 生成指令

请为知识点"{TOPIC}"生成"发展前景"模块。

### 层级要求

**beginner**：
- 用2-3段话描述未来3-5年的大致趋势
- 高亮1个最可能改变游戏规则的方向
- 语言积极但不过度乐观

**intermediate**：
- 多情景分析：乐观、基准、悲观三种情景
- 每个情景给出关键假设和触发条件
- 估算市场/技术规模的增长趋势图

**expert**：
- 技术轨道分析：技术演进的必然与偶然
- 颠覆可能性评估：哪些现存范式可能被推翻
- 不确定性分析：最大变数是什么
- 类比历史：类似技术的历史发展轨迹

### 必须输出
- beginner: 趋势描述
- intermediate: 3情景分析 + 1张趋势预测图（折线图）
- expert: 技术轨道+颠覆评估 + 2+张分析图

### 质量检查清单
- [ ] 预测是否有逻辑依据（非空想）？
- [ ] 是否区分了短期和长期前景？
- [ ] 情景假设是否明确标注？
- [ ] 是否避免了过度夸张的预测？
