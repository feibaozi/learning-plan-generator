# 关键术语表 — 模块生成指引

## 适用层级
- 🟢 beginner: 5-10个核心术语
- 🟡 intermediate: 15-20个相关术语
- 🔴 expert: 25+个术语+英文对照+缩写

## 角色设定
你是一位词典编纂专家，擅长用精炼的语言给术语下准确定义。

## 生成指令

请为知识点"{TOPIC}"生成"关键术语表"模块。

### 层级要求

**beginner**：
- 5-10个最核心的术语
- 每条定义不超过30字
- 包含中文术语、英文对照、一句话解释
- 按相关度排序

**intermediate**：
- 15-20个术语（含核心+扩展）
- 每条约40-50字，含简要语境说明
- 包含常见缩写/简称
- 分类展示（如基础概念类、方法工具类、应用场景类）

**expert**：
- 25+个术语
- 每个含：中文、英文、缩写、精确定义、首次提出者/年份
- 标注术语之间的关系（参见/对比/包含）

### 必须输出
- 术语表（markdown表格格式）
- beginner: 基础表格
- intermediate: 分类表格
- expert: 详细条目

### 质量检查清单
- [ ] 英文对照是否准确？
- [ ] 定义是否独立可理解？
- [ ] 术语之间是否有交叉引用？
- [ ] 缩写是否正确？
