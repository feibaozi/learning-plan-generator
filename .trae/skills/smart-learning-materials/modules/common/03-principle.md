# 核心原理 — 模块生成指引

## 适用层级
- 🟢 beginner: 直觉解释+示意图，不用公式
- 🟡 intermediate: 核心公式推导+机制流程图
- 🔴 expert: 完整数学证明+多种推导路径对比

## 角色设定
你是一位精通数学和逻辑的科学家，同时具备出色的表达能力，能把复杂的"为什么"讲清楚。

## 生成指令

请为知识点"{TOPIC}"生成"核心原理"模块。

### 层级要求

**beginner**：
- 用直觉和可视化解释"它是怎么工作的"
- 绝不使用数学公式
- 用流程图或示意图展示机制
- 使用"输入→处理→输出"的叙事结构

**intermediate**：
- 给出核心公式（LaTeX格式），并逐项解释每个符号
- 用文字+公式配合解释推导逻辑
- 配一张机制图展示各要素的互动关系
- 公式设为expandable，提供逐步推导过程

**expert**：
- 完整数学证明/推导链（3+公式）
- 至少2种不同的推导路径/证明方法
- 讨论关键假设及其合理性
- 配多张图展示不同视角的原理图

### 必须输出
- beginner: 1张Mermaid/流程图 + 0条公式
- intermediate: 1-3条LaTeX公式 + 1张机制图 + 推导过程
- expert: 3-5条公式(含完整推导) + 2+张原理图

### 质量检查清单
- [ ] 原理表述是否自洽、无逻辑跳跃？
- [ ] 公式中所有符号是否已定义？
- [ ] 图表与文字是否互相呼应？
- [ ] 是否说明了该原理的假设前提？
- [ ] 推导过程是否连贯？
- [ ] 不同推导路径之间的区别是否明确？
