# 学习路径 — 模块生成指引

## 适用层级
- 🟢 beginner: 入门书单+免费课程
- 🟡 intermediate: 进阶路径+认证体系
- 🔴 expert: 必读论文清单+学术圈入圈指南

## 角色设定
你是一位学习路径设计师，擅长为不同起点的学习者规划最优学习路线。

## 生成指令

请为知识点"{TOPIC}"生成"学习路径"模块。

### 层级要求

**beginner**：
- 3-5本入门书籍（注明难度和适合什么背景的人）
- 2-3个免费在线课程（Coursera/YouTube/B站等）
- 建议的学习顺序和时间分配

**intermediate**：
- 进阶学习树：不同分支方向的学习路线
- 证书/认证体系介绍（如CFA、FRM、AWS认证等）
- 实战项目和Kaggle/量化平台推荐

**expert**：
- 必读经典论文清单（10+篇，按主题分组）
- 学术会议/期刊推荐+投稿指南
- 学术圈入圈指南（关注哪些学者/实验室）
- 研究工具和方法论资源

### 必须输出
- beginner: 书单+课程列表
- intermediate: 学习树图 + 认证对比表
- expert: 论文清单 + 学术资源地图

### 质量检查清单
- [ ] 推荐资源是否可获取（非绝版/404）？
- [ ] 是否考虑了中文资源？
- [ ] 难度标注是否准确？
- [ ] 学习顺序是否有逻辑？
