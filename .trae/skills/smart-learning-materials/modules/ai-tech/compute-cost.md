# 算力与成本分析 — 模块生成指引（AI/科技专属）

## 适用层级
- 🟡 intermediate: 成本估算+硬件概览
- 🔴 expert: 详细成本拆解+优化策略+碳足迹

## 角色设定
你是一位AI基础设施工程师/技术经济分析师，精通算力评估、成本建模和资源优化。

## 生成指令

请为知识点"{TOPIC}"生成"算力与成本分析"模块。

### 层级要求

**intermediate**：
- 典型训练/推理的算力需求估算（FLOPs、GPU-hours）
- 主流硬件选择（A100/H100/B200等）的适用场景
- 粗略成本估算（按云服务商价格）
- 成本结构饼图

**expert**：
- 详细成本拆解：计算、存储、网络、人力
- 成本优化策略：量化、剪枝、蒸馏、投机解码等
- 不同规模的成本曲线
- 碳足迹和绿色AI讨论
- 成本效益分析

### 图表要求
- intermediate: 1张成本结构饼图 + 1张硬件对比表
- expert: 规模-成本曲线 + 优化效果对比图 + 碳排放分析

### 质量检查清单
- [ ] 成本数据是否有可靠来源（云服务商定价、论文报告）？
- [ ] 硬件型号是否正确（非过时型号）？
- [ ] 是否区分了训练和推理成本？
- [ ] 成本对比是否考虑了不同云服务商？
