💻 **代码示例**：

```python
import numpy as np
from scipy import stats

# MLE 示例：估计高斯分布的参数
data = np.random.randn(1000) * 2 + 5  # 真值: μ=5, σ=2
mu_mle = np.mean(data)
sigma_mle = np.std(data, ddof=0)
print(f"MLE: μ={mu_mle:.3f}, σ={sigma_mle:.3f}")

# 贝叶斯更新：Beta-Binomial 共轭
def bayesian_update(prior_alpha, prior_beta, successes, trials):
    posterior_alpha = prior_alpha + successes
    posterior_beta = prior_beta + trials - successes
    return posterior_alpha, posterior_beta
```

📐 **关键公式**：

- **贝叶斯定理**：`P(θ|X) = P(X|θ)P(θ) / P(X)`
- **MLE**：`θ̂_MLE = argmax P(X|θ)`
- **梯度下降更新**：`θ_{t+1} = θ_t - η∇L(θ_t)`

💻 **代码示例**：

```python
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(64 * 7 * 7, 10)
    
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        x = x.view(x.size(0), -1)
        return self.fc(x)
```

📐 **关键公式**：

- **前向传播**：`a^(l) = σ(W^(l)a^(l-1) + b^(l))`
- **反向传播**：`δ^(l) = (W^(l+1))ᵀδ^(l+1) ⊙ σ'(z^(l))`
- **Adam 更新**：`θ_{t+1} = θ_t - η · m̂_t / (√v̂_t + ε)`

💻 **代码示例**：

```python
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def forward(self, x, mask=None):
        B, T, D = x.shape
        Q = self.W_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        
        scores = Q @ K.transpose(-2, -1) / (self.d_k ** 0.5)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = torch.softmax(scores, dim=-1)
        out = (attn @ V).transpose(1, 2).contiguous().view(B, T, D)
        return self.W_o(out)
```

📐 **关键公式**：

- **Self-Attention**：`Attention(Q, K, V) = softmax(QKᵀ/√d_k)V`
- **Transformer 前向**：`FFN(x) = W₂·ReLU(W₁·x)`
- **RLHF 目标**：`max E[r(x,y) - β·KL(π_θ(y|x) || π_ref(y|x))]`

## 核心公式与概念速查表

### 表1：概率与统计

| 名称 | 公式 |
|------|------|
| 贝叶斯定理 | `P(θ\|X) = \frac{P(X\|θ)P(θ)}{P(X)}` |
| 高斯分布 | `\mathcal{N}(x\|μ,σ²) = \frac{1}{\sqrt{2πσ²}} e^{-\frac{(x-μ)²}{2σ²}}` |
| MLE | `\hat{θ}_{\text{MLE}} = \arg\max_θ \prod_{i=1}^n P(x_i\|θ)` |
| 大数定律 | `\bar{X}_n \xrightarrow{P} μ \text{ as } n → ∞` |
| 中心极限定理 | `\frac{\bar{X}_n - μ}{σ/\sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1)` |

### 表2：线性回归与分类

| 名称 | 公式 |
|------|------|
| OLS 估计 | `\hat{β} = (X^{\top}X)^{-1}X^{\top}y` |
| Ridge 回归 | `\hat{β}_{\text{ridge}} = (X^{\top}X + λI)^{-1}X^{\top}y` |
| Lasso 回归 | `\hat{β}_{\text{lasso}} = \arg\min_β \{\|y-Xβ\|² + λ\|β\|_1\}` |
| Sigmoid 函数 | `σ(z) = \frac{1}{1 + e^{-z}}` |
| 交叉熵损失 | `\mathcal{L} = -\frac{1}{n}\sum[y_i\log\hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]` |

### 表3：神经网络与深度学习

| 名称 | 公式 |
|------|------|
| 前向传播 | `a^{(l)} = σ(W^{(l)}a^{(l-1)} + b^{(l)})` |
| 反向传播 δ 递推 | `δ^{(l)} = (W^{(l+1)})^{\top}δ^{(l+1)} ⊙ σ'(z^{(l)})` |
| Momentum SGD | `v_t = βv_{t-1} + (1-β)∇L(θ_t); θ_{t+1} = θ_t - η v_t` |
| Adam | `m_t = β₁m_{t-1} + (1-β₁)g_t; v_t = β₂v_{t-1} + (1-β₂)g_t²` |
| BatchNorm | `\hat{x} = \frac{x - μ_B}{\sqrt{σ²_B + ε}}; y = γ\hat{x} + β` |

### 表4：无监督学习与降维

| 名称 | 公式 |
|------|------|
| PCA 协方差分解 | `C = \frac{1}{n}X^{\top}X = VΛV^{\top}` |
| K-Means 目标 | `J = \sum_{k=1}^K \sum_{x_i \in C_k} \|x_i - μ_k\|²` |
| GMM 似然 | `P(x\|θ) = \sum_{k=1}^K π_k \mathcal{N}(x\|μ_k, Σ_k)` |
| t-SNE 相似度 | `p_{j\|i} = \frac{\exp(-\|x_i-x_j\|²/2σ_i²)}{\sum_{k≠i}\exp(-\|x_i-x_k\|²/2σ_i²)}` |
| DBSCAN 核心点 | `\|N_ε(p)\| ≥ \text{minPts}` |

### 表5：Transformer 与大模型

| 名称 | 公式 |
|------|------|
| Self-Attention | `\operatorname{Attention}(Q,K,V) = \operatorname{softmax}(\frac{QK^{\top}}{\sqrt{d_k}})V` |
| 多头注意力 | `\operatorname{MultiHead} = \operatorname{Concat}(\text{head}_1,...,\text{head}_h)W^O` |
| 位置编码 (Sinusoidal) | `\operatorname{PE}(pos,2i) = \sin(pos/10000^{2i/d}); \operatorname{PE}(pos,2i+1) = \cos(pos/10000^{2i/d})` |
| Language Modeling Loss | `\mathcal{L} = -\frac{1}{T}\sum_{t=1}^T \log P(w_t\|w_{<t})` |
| RLHF PPO 目标 | `\max_θ \mathbb{E}[r(x,y) - β·\operatorname{KL}(π_θ(y\|x) \| π_{\text{ref}}(y\|x))]` |
