## 总体学习路线图

### 学习目标

1. **识茶**：掌握六大茶类分类体系，能通过外形、汤色、叶底辨识常见茶品
2. **喝茶**：掌握不同茶类的冲泡技法，能根据茶性选择合适的水温、茶具和冲泡方式
3. **品茶**：建立系统的感官品评能力，能用专业术语描述茶的风味特征

### 核心学习哲学

> 先看清森林，再走进树木——系统全景图是你所有学习的地图

茶文化知识高度系统化：六大茶类按发酵度排列形成清晰光谱，冲泡参数与茶类一一对应，品评方法有标准五步流程。用系统图解的方式学习，能快速建立整体认知框架，再逐层深入细节。

## 系统图解学习法

本方案采用系统图解法组织学习，核心步骤：

### 步骤1：绘制全景分类图

首先画出六大茶类的全景分类图，标注发酵度、核心工艺和代表茶品，建立整体认知框架。

```
发酵度:  0%        5-10%     10-20%     15-70%     70-95%    80-100%
         │          │          │          │          │          │
茶类:   绿茶 ──── 白茶 ──── 黄茶 ──── 乌龙茶 ──── 红茶 ──── 黑茶
         │          │          │          │          │          │
工艺:   杀青      萎凋      闷黄      做青       全发酵    后发酵
         │          │          │          │          │          │
代表:   龙井      白毫银针   君山银针   铁观音     祁门红茶   普洱茶
       碧螺春     白牡丹     蒙顶黄芽   大红袍     滇红       六堡茶
```

### 步骤2：构建参数适配矩阵

将水温、茶具、冲泡时间等参数与茶类一一对应，形成可查阅的适配矩阵表。

| 参数 | 绿茶 | 白茶 | 黄茶 | 乌龙茶 | 红茶 | 黑茶 |
|------|------|------|------|--------|------|------|
| 水温 | 80-85°C | 85-90°C | 80-85°C | 95-100°C | 90-95°C | 100°C |
| 茶具 | 玻璃杯 | 盖碗 | 玻璃杯 | 紫砂壶 | 瓷壶 | 紫砂壶 |
| 投茶量 | 3g/150ml | 5g/150ml | 3g/150ml | 7-8g/110ml | 5g/150ml | 7-8g/110ml |
| 首泡时间 | 1-2min | 1-2min | 1-2min | 5-10s | 3-5min | 10-20s |

### 步骤3：绘制流程关系图

为功夫茶冲泡、品评五步法等流程绘制步骤图，将文字知识转化为可视化流程。

### 步骤4：标注关联与差异

在图中标注知识点间的关联（如品种→工艺→风味）和差异（如不同茶类冲泡参数对比）。

## 实操练习题库

### 🟢 基础题

1. **辨识六大茶类** — 给定5款干茶样本，按发酵度从低到高排序
2. **水温匹配练习** — 为绿茶、乌龙茶、红茶、黑茶分别选择最佳冲泡水温
3. **茶具识别** — 识别盖碗、紫砂壶、玻璃杯、瓷壶并说明各自最适合的茶类

### 🟡 进阶题

4. **冲泡对比实验** — 同一款乌龙茶用不同水温(80°C/90°C/100°C)冲泡，记录汤色、香气、滋味差异
5. **风味描述训练** — 盲品3款茶，用标准术语描述香气类型和滋味特征
6. **功夫茶流程实操** — 完整执行功夫茶冲泡7步流程，记录每步时间与操作要点

### 🔴 挑战题

7. **跨茶类品评报告** — 选择同一产区(如武夷山)的绿茶、乌龙茶、红茶，撰写对比品评报告
8. **茶会策划与执行** — 设计一场主题茶会(含茶单、茶具、茶食、流程)，并执行完整茶会

### 📦 项目题

9. **个人茶品鉴手册** — 建立20款茶的品鉴记录(含干茶/汤色/香气/滋味/叶底评分)
10. **家居茶室搭建方案** — 规划并搭建一个家庭茶饮空间(含茶具选购、茶叶储备、冲泡区设计)
