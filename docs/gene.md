## 一、总体学习路线图

### 学习目标
能够系统掌握基因工程的核心理论与实验技能：
- 理解 DNA 复制、转录、翻译的分子机制
- 掌握限制酶、连接酶、载体系统的设计原理
- 能够独立设计克隆实验和基因编辑方案
- 了解基因治疗、CAR-T、合成生物学等前沿应用
- 具备基本的生物信息学分析能力

### 核心理念

> **"基因工程 = DNA 的剪切 + 粘贴"**——本质上就是对 DNA 进行精确的酶切和连接操作，但每一步都充满了分子层面的精细调控。

> **"一张通路图抵过千字描述"**——信号通路、克隆策略、编辑机制都是空间性的、流程性的，必须画出来才能理解。本方案在每个关键节点配有图解指南。

> **"实验是基因工程的最终裁判"**——每一个理论都需要通过 PCR、电泳、测序来验证。本方案强调实验设计的思维。

## 图解学习法

### 为什么基因工程必须用图来学

基因工程中 80% 的"学不会"来自无法在脑中构建分子操作的三维/流程图像——而图示是唯一的桥梁。

### 三遍画图法

| 遍数 | 方法 | 目标 |
|------|------|------|
| **第一遍：抄图** | 照着教材画 PCR 三步骤、质粒图谱、CRISPR 机制 | 理解有什么组件、它们怎么连接 |
| **第二遍：默图** | 不看资料，凭理解画出 Gibson 组装流程或信号通路 | 检验是否真的理解，暴露记忆漏洞 |
| **第三遍：讲图** | 指着自己画的图向别人（或镜子）讲明白 | 能讲清楚才是真理解——费曼学习法 |

### 画图难度分级

| 级别 | 标记 | 含义 |
|------|------|------|
| [必画] | ★★★ | 核心概念——不画学不会（如 PCR 原理、CRISPR 机制） |
| [建议画图] | ★★☆ | 重要概念——画了加深理解（如质粒图谱、蛋白纯化流程） |
| [可选画图] | ★☆☆ | 辅助理解——学有余力时画（如 NGS 库构建） |

## 二、第一阶段：分子生物学基础

**时间：第1-2周（每天1.5-2h）**

### 学习目标
理解 DNA 的化学结构、中心法则的每一步、PCR 的原理和凝胶电泳的物理基础。

### 2.1 DNA 双螺旋结构与碱基配对 `[分子]`

#### 核心知识点

**DNA 的化学组成：**
```
核苷酸 = 碱基 + 脱氧核糖 + 磷酸

碱基: A(腺嘌呤) T(胸腺嘧啶) G(鸟嘌呤) C(胞嘧啶)
配对: A=T (2氢键)  G≡C (3氢键)  ← 了解GC含量影响Tm值的物理原因
```

**B-DNA 双螺旋参数 [必画]：**
```
直径: 2.0 nm
螺距: 3.4 nm (10.5 bp/圈)
大沟宽度: 2.2 nm (蛋白质识别位点!)
小沟宽度: 1.2 nm
```

#### 关键概念：为什么 GC 含量越高 DNA 越稳定？

```
[化学解释]
GC 配对有 3 个氢键，AT 只有 2 个
→ GC 越多，双链分离所需能量越高
→ Tm (解链温度) = 4(G+C) + 2(A+T) [Wallace法则近似]

[生物学意义]
高温菌基因组 GC 含量通常更高 (>60%)
PCR 引物设计需平衡 GC 含量 (40-60%)
```

#### Tm 值计算 `[数学]`

```
简化公式 (Wallace法则, <20bp):
Tm = 4°C × (G+C数量) + 2°C × (A+T数量)

精确公式 (SantaLucia, >20bp):
Tm = ΔH/(ΔS + R·ln(C/4)) - 273.15
```

### 2.2 中心法则 `[分子]`

```
[必画] 完整中心法则流程图:

复制(DNA → DNA)
   │
   ↓
转录(DNA → mRNA) ──→ 逆转录(RNA → DNA)
   │                    [逆转录病毒/RT-PCR]
   ↓
翻译(mRNA → 蛋白质)
   │
   ↓
折叠+修饰 → 功能蛋白
```

**关键细节——每一步都是分子机器的工作：**

| 步骤 | 核心酶 | 底物 | 方向 | 能量来源 |
|------|--------|------|------|---------|
| DNA 复制 | DNA 聚合酶 | dNTP | 5'→3' | dNTP 水解(焦磷酸) |
| 转录 | RNA 聚合酶 | NTP | 5'→3' | NTP 水解 |
| 翻译 | 核糖体( rRNA+蛋白) | 氨酰-tRNA | N→C | GTP(延伸因子) |

**转录起始——原核 vs 真核 [必画]：**
```
原核:                    真核:
-35区  -10区(Pribnow)    TATA盒  INR  DPE
TTGACA TATAAT             TATAAA  +1
  │      │                  │
RNA Pol全酶(σ因子)      TFIID→TFIIB→...→RNA Pol II
直接结合启动子           多步组装(需要多个通用转录因子)
```

### 2.3 PCR 聚合酶链式反应 `[酶学]`

#### PCR 三步原理 [必画]

```
┌─────────────────────────────────────────────┐
│               PCR 一个循环                    │
├─────────────────────────────────────────────┤
│ 1. 变性 94-98°C  (30s)                      │
│    dsDNA ──→ ssDNA                          │
│    ┌─────┐        ┌──┐   ┌──┐               │
│    │││││││  ──→   │  │ + │  │               │
│    └─────┘        └──┘   └──┘               │
│                                              │
│ 2. 退火 50-65°C  (30s)                      │
│    引物特异性结合靶序列                       │
│    ┌──┐  ←引物结合                           │
│    │  │===────                               │
│    └──┘                                     │
│                                              │
│ 3. 延伸 72°C  (1kb/min)                     │
│    Taq 聚合酶从引物 3'-OH 延伸               │
│    ┌──┐                                     │
│    │  │===──────────→ 5'→3'                 │
│    └──┘    新合成链                          │
└─────────────────────────────────────────────┘

n个循环后: 理论产物 = 起始模板 × 2^n
实际极限: ~10^6 ~ 10^7 倍 (受限于酶活性衰减+dNTP耗尽)
```

#### 引物设计黄金法则

```
1. 长度: 18-25 bp (太短不特异, 太长退火慢)
2. GC含量: 40-60%
3. Tm值: 正反向引物 Tm 差 < 5°C
4. 3' 端: 最后一个碱基最好是 G 或 C (GC夹)
5. 避免: 发夹结构、自身二聚体、交叉二聚体
6. 避免: 3' 端连续 3 个以上 G/C (防止非特异结合)
```

#### 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 无产物 | 模板降解/引物设计错误 | 重新设计引物，检查模板 |
| 非特异条带 | 退火温度太低 | 提高退火温度(梯度PCR) |
| 引物二聚体 | 引物互补 | 重新设计引物 |
| 拖尾/smear | Mg²⁺太多或酶太多 | 优化Mg²⁺浓度 |

### 2.4 凝胶电泳 `[分子]`

#### 琼脂糖 vs PAGE

```
琼脂糖凝胶 (0.5-3%):
→ 分离: 200 bp ~ 50 kb
→ 浓度越低, 大片段分离越好
→ 水平电泳

PAGE (聚丙烯酰胺凝胶, 3.5-20%):
→ 分离: 10 bp ~ 1 kb
→ 分辨率可达 1 bp (测序胶!)
→ 垂直电泳

DNA 迁移速率 ∝ 1/log(分子量)
因为: 凝胶=分子筛, 小分子穿得快
```

### 2.5 Python 实战：PCR 引物分析

```python
# 引物 Tm 值计算 (Wallace简化公式)
def tm_wallace(seq):
    return 4 * (seq.count('G') + seq.count('C')) + 2 * (seq.count('A') + seq.count('T'))

# GC含量
def gc_content(seq):
    return (seq.count('G') + seq.count('C')) / len(seq) * 100

# 检查发夹结构 (简化的回文检测)
def has_hairpin(seq, min_stem=4, min_loop=3):
    for i in range(len(seq) - min_stem*2 - min_loop):
        for j in range(i+min_stem*2+min_loop, len(seq)):
            if seq[i:i+min_stem] == reverse_complement(seq[j-min_stem+1:j+1]):
                return True
    return False
```

## 三、第二阶段：工具酶与载体系统

**时间：第3-4周（每天1.5-2h）**

### 学习目标
掌握限制性内切酶的分类和切割机制，质粒载体的核心元件设计，感受态的制备与转化原理。

### 3.1 限制性内切酶 `[酶学]`

#### 三大类型对比 [必画]

```
I 型: 识别位点 + 切割位点 距离几百~几千bp
      → 几乎不用在基因工程中

II 型: 识别 = 切割位点 (或非常接近)
      → 基因工程的绝对主力!
      例: EcoRI  G^AATTC
           HindIII A^AGCTT
           BamHI   G^GATCC

III 型: 识别位点 和 切割位点 距离 25-27bp
      → 较少使用
```

#### 粘性末端 vs 平末端 [必画]

```
粘性末端 (EcoRI):          平末端 (SmaI):
5'-G       AATTC-3'         5'-CCC      GGG-3'
3'-CTTAA       G-5'         3'-GGG      CCC-5'
    ↑     ↑                       ↑  ↑
   5'突出端                    平末端(无突出)

粘性末端连接效率 > 平末端 (因为碱基配对提供预稳定)
平末端可以连接任何平末端 → 灵活性更高
```

#### 同尾酶与兼容末端

```
同尾酶(Isoschizomer): 识别相同序列
  例: SphI (GCATG^C) = PaeI (GCATG^C)

兼容末端(Compatible cohesive ends):
  不同酶切出相同的突出序列
  例: BamHI  (G^GATCC) → 5'-GATC
      BglII  (A^GATCT) → 5'-GATC  ← 末端相同!
  → BamHI+BglII 切割片段可以互相连接
```

### 3.2 DNA 连接酶 `[酶学]`

```
T4 DNA 连接酶(最常用, 来自 T4 噬菌体):
→ 催化 5'-磷酸 + 3'-OH → 磷酸二酯键
→ 需要 ATP 提供能量
→ 粘性末端: 16°C 过夜 或 室温 1-2h
→ 平末端: 16°C 过夜 (效率更低, 可加 PEG 促进)

反应机理 [建议画图]:
ATP + 酶 → 酶-AMP + PPi
酶-AMP + 5'-磷酸 → 激活的 5'-磷酸
激活的 5'-磷酸 + 3'-OH → 磷酸二酯键 + AMP
```

### 3.4 感受态制备与转化 [载体]

#### 化学转化法 [必画]

```
CaCl₂ 法制备感受态 (Hanahan 1983):

对数早期菌 (OD600≈0.3-0.5)
    ↓ 冰浴 + 离心
菌体
    ↓ 重悬于冷 CaCl₂ (0.1M) 
    ↓ 冰浴 20-30 min → 再次离心
感受态细胞 (可加甘油, -80°C 保存)

转化:
感受态 + 质粒 DNA
    ↓ 冰浴 30 min
    ↓ 42°C 热激 45-90 sec (关键步骤!)
    ↓ 立刻冰浴 2 min
    ↓ +LB → 37°C 复苏 45-60 min
涂板 (+抗生素)
```

**为什么 CaCl₂？**
```
Ca²⁺ 中和细胞壁的负电荷
→ DNA 更容易靠近细胞膜
→ 热激时膜通透性增加 → DNA 进入
```

#### 电转化法 (效率更高的替代方案)

```
原理: 短促高压电脉冲 (1.8-2.5 kV)
     → 细胞膜瞬时穿孔
     → DNA 通过孔洞进入

效率: 可达 10^9 ~ 10^10 CFU/μg (比 CaCl₂ 高1-2个数量级!)
注意: 盐会导电→电弧! DNA 和菌必须充分脱盐!
```

## 四、第三阶段：克隆技术与文库构建

**时间：第5-6周（每天1.5-2h）**

### 4.1 TA 克隆 `[酶学]`

```
原理: Taq 聚合酶末端转移酶活性
→ PCR 产物 3' 端自动加一个 A
→ T-载体 3' 端 (线形, 5' 端突出 T)

[必画] 连接示意:

PCR产物: 5'───A-3'  (Taq加A)
              3'-A───5'  
              
T-载体:  5'...T    (T与A配对)
              3' T...5'
              
T4 连接酶 ──→ 环化
```

### 4.2 Gibson 组装 `[酶学]`

#### 一管三酶的神奇反应 [必画]

```
Gibson Assembly (Gibson et al., 2009):

组分:
1. T5 外切核酸酶 → 从 5' 端降解 DNA (产生 3' 突出)
2. Phusion DNA 聚合酶 → 补平缺口
3. Taq DNA 连接酶 → 连接切口

┌────────────────────────────────────┐
│ Step 1: T5 外切酶 5'→3' 降解       │
│         ┌───┐    ┌───┐             │
│ 5'─────→│    │  │   │←────5'      │
│         └───┘  └───┘               │
│                                      │
│ Step 2: 同源臂退火 (~15-40bp)      │
│         ┌───┐──────┐───┐           │
│         │   │======│   │           │
│         └───┘──────┘───┘           │
│                                      │
│ Step 3: 聚合酶补平+连接酶封口      │
│         ┌──────────────┐           │
│         │==============│           │
│         └──────────────┘           │
│ → 完整的环化产物!                   │
└────────────────────────────────────┘

优点: 
- 一步反应 (50°C 15-60 min)
- 不依赖限制酶位点
- 一次可组装 2-6 个片段
```

#### 引物设计策略 [必画]

```
设计用于 Gibson 的引物:
每个片段两端需加 15-40 bp 同源臂
同源臂 = 与相邻片段重叠的序列

片段A:  ───[同源臂15bp]────[目的序列A]────[同源臂15bp]───
                                        │
```

### 4.5 Python 实战：序列模拟与分析

```python
# 查找限制酶位点
RESTRICTION_SITES = {
    'EcoRI': 'GAATTC', 'BamHI': 'GGATCC',
    'HindIII': 'AAGCTT', 'XhoI': 'CTCGAG',
    'NotI': 'GCGGCCGC', 'SmaI': 'CCCGGG'
}

def find_restriction_sites(seq):
    sites = {}
    for enzyme, pattern in RESTRICTION_SITES.items():
        pos = []
        idx = 0
        while True:
            idx = seq.find(pattern, idx)
            if idx == -1: break
            pos.append(idx)
            idx += 1
        if pos: sites[enzyme] = pos
    return sites

# Gibson 引物设计 (简化版)
def design_gibson_primers(fragments, homology_length=20):
    primers = []
    for i, frag in enumerate(fragments):
        # 左同源臂 + 正向
        fwd_homology = fragments[i-1][-homology_length:] if i > 0 else fragments[-1][-homology_length:]
        fwd = fwd_homology + frag[:30]
        # 反向: 下一片段的反向互补 + 当前片段尾
        next_frag = fragments[(i+1) % len(fragments)]
        rev_homology = reverse_complement(next_frag[:homology_length])
        rev = rev_homology + reverse_complement(frag[-30:])
        primers.append((fwd, rev))
    return primers
```

### 5.4 SDS-PAGE `[分子]`

```
原理:
1. SDS (阴离子去垢剂) ──→ 变性蛋白
   + 使所有蛋白带均匀负电荷
   → 迁移率只取决于分子量 (不取决于原始电荷)

2. 浓缩胶 (5%, pH6.8):
   Gly⁻ + Cl⁻ 形成离子梯度 → 蛋白"压缩"成薄带

3. 分离胶 (8-15%, pH8.8):
   蛋白按大小分离, 小蛋白跑得快

迁移率 ∝ log(分子量)
```

#### SDS-PAGE 故障排查

```
 条带歪斜 → 胶不平/电泳缓冲液不均匀
 拖尾 → 蛋白降解/上样量过大
 无条带 → 蛋白未表达/不溶(在包含体中)
 额外条带 → 蛋白降解/杂质
```

### 6.1 CRISPR/Cas9 完整机制 `[编辑]`

#### 天然 CRISPR 免疫系统 [必画]

```
CRISPR = 细菌的"免疫记忆"

阶段1: 适应 (获取新 spacer)
噬菌体DNA → Cas1+Cas2复合物 → 将 protospacer 
(PAM 旁序列) 插入 CRISPR 阵列 ← 获得"记忆"

阶段2: 表达 (crRNA 加工)
CRISPR 阵列 → 转录 pre-crRNA → RNase III + tracrRNA 
→ 成熟 crRNA:tracrRNA 双链

阶段3: 干扰 (切割入侵DNA)
Cas9 + crRNA:tracrRNA → 扫描 PAM (NGG)
→ 与靶序列 20nt 互补配对
→ Cas9 HNH (切互补链) + RuvC (切非互补链)
→ dsDNA 断裂 (DSB, 距 PAM 3nt 上游)
```

#### sgRNA 工程设计 `[编辑]`

```
工程化 sgRNA = crRNA + tracrRNA 融合为单链RNA

sgRNA 结构:
┌──────┬─────────────┬───────┬────────────┐
│5' (20nt)│  cr重复区   │ 四环  │ tracr尾巴  │3'
│  靶点   │  (~12nt)   │       │  (~60nt)  │
└──────┴─────────────┴───────┴────────────┘
  ↑                                    ↑
 识别靶DNA                    Cas9蛋白结合支架
```

#### PAM 的重要性

```
PAM (Protospacer Adjacent Motif, NGG for SpCas9)
= Cas9 的"安全检查点"

作用: 区分自身 (CRISPR 阵列无 PAM) 和 入侵DNA

[必理解]:
- PAM 决定 Cas9 结合第一步 (PAM识别 → 随后DNA解旋)
- 没有 PAM → Cas9 根本不结合 → 不能切割
- 不同 Cas 同源蛋白识别不同 PAM:
  SpCas9: NGG
  SaCas9: NNGRRT  
  Cpf1(Cas12a): TTTV
→ PAM 多样性 = 靶向更多基因组位点的关键!
```

### 6.2 DSB 修复通路 `[编辑]`

#### NHEJ vs HDR [必画]

```
DSB (DNA双链断裂)
        │
    ┌───┴───┐
    ↓       ↓
  NHEJ     HDR
(非同源末端连接)  (同源重组修复)
    │       │
    │       需要同源模板 (donor DNA)
    │       │

 │          │

indel突变   精确的基因替换/插入

```

**策略选择：**

```
要做基因敲除(KO):
→ sgRNA 靶向早期编码外显子
→ 依赖 NHEJ 产生 indel 移码 → 提前终止 → 无功能蛋白

要做点突变/精确敲入(KI):
→ 提供 donor DNA (ssODN 或双链 donor)
→ 依赖 HDR → 精确替换
→ HDR 效率通常远低于 NHEJ → 需要优化
```

### 6.3 新一代编辑工具 `[编辑]`

#### 碱基编辑器 (Base Editor)

```
CBE (胞嘧啶碱基编辑器) = Cas9n(D10A nicking) + APOBEC1 + UGI
→ C→T (G→A) 转换, 无需 DSB

ABE (腺嘌呤碱基编辑器) = Cas9n + TadA-TadA* (进化来的腺嘌呤脱氨酶)
→ A→G (T→C) 转换, 无需 DSB

关键优势:
- 不产生 DSB → 大大降低 indel 风险
- 效率高 (可达 >50%)
- 适合纠正点突变 (人类 ~60% 疾病相关SNP是 C→T 或 T→C!)
```

#### 先导编辑 (Prime Editing)

```
PE = Cas9n(H840A) + M-MLV 逆转录酶
    + pegRNA (含 RT 模板 + PBS 引物结合位点)

过程:
1. Cas9n 切割含 PAM 的链 (产生 3' flap)
2. PBS 与 3' flap 结合
3. 逆转录酶按 RT 模板合成新 DNA
4. 细胞修复 → 引入编辑

优势:
- 理论上可以替换任意序列 (插入/删除/点突变均可)
- 不依赖 DSB 和 HDR
- 适用范围远超碱基编辑器

局限:
- 效率低于碱基编辑器 (仍在优化)
- pegRNA 设计更复杂
```

### 6.4 sgRNA 设计原则 `[统计]`

```
1. 特异性评分 (on-target):
   - GC含量 40-70%
   - 避免 4+ 个连续 T (Pol III 终止信号)
   
2. 脱靶风险评估 (off-target):
   - 用 BLAST/Bowtie 检查基因组中相似序列
   - 种子序列 (PAM 近端 10-12nt) 最重要
   - MIT 评分 / CFD 评分 (流行的脱靶预测算法)

3. 多用 2-3 条 sgRNA → 取效率最高的
4. 优先选 5' 端 (越早出现 STOP ≈ 越有效的 KO)
```

### 6.5 Python实战：sgRNA 脱靶分析

```python
def sgRNA_design(genome_seq, target_start, pam='NGG'):
    """查找靶位点附近的 sgRNA"""
    target_region = genome_seq[target_start-200:target_start+200]
    guides = []
    for i in range(len(target_region)-30):
        # 检查 PAM (NGG)
        pam_seq = target_region[i+20:i+23]
        if (pam_seq[1]=='G' and pam_seq[2]=='G' and 
            pam_seq[0] in 'ACGT'):
            guide_seq = target_region[i:i+20]
            gc = (guide_seq.count('G')+guide_seq.count('C'))/20
            if gc >= 0.4 and gc <= 0.7:
                guides.append({
                    'seq': guide_seq, 'gc': gc,
                    'position': target_start - 200 + i,
                    'pam': pam_seq
                })
    return guides

# 脱靶评分简化 (MIT 评分基于种子序列匹配)
def mit_score(on_target, off_target):
    """简化 MIT 规则"""
    # 统计种子区错配位置加权
    seed_scores = {0: 0.2, 1: 0.2, 2: 0.3, 3: 0.3, 
                   4: 0.5, 5: 0.5, 6: 1.0, 7: 1.0, 
                   8: 1.2, 9: 1.2, 10: 1.5, 11: 1.5}
    mm_count = sum(1 for a,b in zip(on_target[:12], off_target[:12]) if a!=b)
    if mm_count > 2: return 0  # 种子区太多错配 → 低脱靶
    return 100 / (1 + mm_count)
```

#### 关键概念：RPKM vs FPKM vs TPM

```
RPKM (Reads Per Kilobase per Million mapped reads)
= 读段数 / (基因长度/1000 × 总reads/1,000,000)

TPM (Transcripts Per Million) 
= RPKM / Σ(RPKM) × 1,000,000

为什么用TPM? 
→ TPM 在不同样品间可比 (消除了文库大小+基因长度差异)
```

### 8.3 BLAST 序列比对 `[组学]`

```
BLAST (Basic Local Alignment Search Tool)

类型:
BLASTn: DNA → DNA
BLASTp: 蛋白 → 蛋白
BLASTx: DNA → 翻译为蛋白 → 蛋白数据库 (六读框翻译!)
tBLASTn: 蛋白 → 在翻译的DNA数据库中搜索

关键参数:
E-value (期望值): 随机匹配到这个得分以上的期望次数
→ E < 0.001 = 显著匹配
→ E 越小, 越可信

Bit score: 归一化相似度 (越高越像)
→ 独立于数据库大小, 可直接比较
```

### 8.4 关键统计概念 [统计]

```
多重假设检验校正 (RNA-seq 你用得到!):

做20,000个基因的差异表达检验 →
即使全无差异 (H0), 期望 20,000×0.05 = 1000个假阳性!

校正方法:
Bonferroni: p × n (最严格 → 基本全不显著)
Benjamini-Hochberg (FDR): 
  排序 p值 → 每个p × n/i (i为排序) → 控制假发现率

→ RNA-seq 分析中用 adj.p (FDR) 而非 raw p !
```
