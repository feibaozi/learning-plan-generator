## 总体学习路线图

### 🎯 学习目标

1. 掌握打野位的核心定位——全队节奏发动机、资源分配者、地图控制者
2. 精通常用打野英雄池（刺客/战士/蓝领三类至少各2名）
3. 建立完整的时间轴意识：1:30河道蟹→2:00暴君/主宰→4:00防御塔护盾消失→10:00黑暗暴君/暗影主宰→20:00风暴龙王
4. 培养读图能力：通过小地图信息预判敌方打野位置和意图
5. 能够根据阵容进行合理的BP（Ban/Pick）决策，并灵活调整前期路线

### 🧭 核心理念

> **"打野不是刷野，是掌控时间和空间的艺术"**
> — 每一组野怪的刷新间隔（70s小野/90s红蓝buff）都是你的时钟；每一条河道都是你的棋盘

> **"Gank不是为了杀人，是为了创造人数差和资源差"**
> — 成功的Gank是逼出闪现=下波必杀；逼回城=免费推塔；击杀=滚雪球

> **"视野是MOBA游戏的第一生产力"**
> — 知道自己在哪不重要，知道敌人在哪才值钱

## 图解学习法

### 为什么打野需要图解学习？

打野是王者荣耀中最依赖**空间思维**和**时间逻辑**的位置。传统的文字攻略无法直观传达"Gank路线选择"、"视野覆盖范围"、"反野时机"这些核心概念。画图能帮助你将抽象的地图意识具象化。

### 三步法

| 步骤 | 方法 | 打野示例 |
|------|------|---------|
| **抄图** | 对着小地图手绘野区布局、Gank路线、视野点位 | 画出蓝开→三狼→红→抓下的标准路线 |
| **默图** | 不看参考，凭记忆还原关键路线和时机 | 默画敌方打野"蓝开抓下"的入侵路线 |
| **讲图** | 向自己/队友讲解图中每一步的决策逻辑 | "为什么这个时间点选择反红而不是抓中" |

### 画图层级

- **[必画]** — 野区路线图（6条标准开局路线）、Gank优先级判定流程、资源刷新时间轴
- **[建议画]** — 英雄技能连招流程图、团战站位图、逆风翻盘决策树
- **[可选画]** — BP博弈矩阵、英雄Counter关系网、赛季版本变化时间线

### 推荐视觉资源

- 王者营地App → 对局回顾 → 查看自己的行走路线热力图
- 王者荣耀官方地图文件（可用于标注和分析）
- 职业比赛小地图回放（KPL官方录像）

### 技能列表

- [节奏] `掌握野区基础刷新机制：红蓝buff 90s、小野 70s、河道蟹 60s`
- [视野] `学习基础视野概念：河道草丛、buff草丛、龙坑视野`
- [节奏] `建立时间轴意识：1:30河道蟹→2:00龙刷新→第一条龙的战略价值`

### 图解

```
打野位决策金字塔：

        ┌──────────────┐
        │   创造优势    │  ← 终极目标
        ├──────────────┤
        │ 推塔 · 拿龙  │  ← 中期目标
        ├──────────────┤
        │  Gank · 反野 │  ← 前期手段
        ├──────────────┤
        │  刷野 · 发育 │  ← 基础运营
        └──────────────┘

标准红开路线（蓝方）：
   红buff → 三猪 → 蓝buff → 河道蟹 → 抓上/中 → 回红区
   [0:30]   [0:45]  [1:05]    [1:30]    [1:35]    [2:00]
```

### 代码

```python
# 打野效率计算器
JUNGLE_CAMPS = {
    "红buff":  {"exp": 120, "gold": 85,  "respawn": 90},
    "蓝buff":  {"exp": 120, "gold": 85,  "respawn": 90},
    "三猪":    {"exp": 75,  "gold": 55,  "respawn": 70},
    "双狼":    {"exp": 65,  "gold": 45,  "respawn": 70},
    "蜥蜴":    {"exp": 80,  "gold": 50,  "respawn": 70},
    "河道蟹":  {"exp": 90,  "gold": 70,  "respawn": 60},
}

def route_efficiency(route, clear_time_sec):
    """计算路线效率（经验/秒）"""
    total_exp = sum(JUNGLE_CAMPS[camp]["exp"] for camp in route)
    return total_exp / clear_time_sec

blue_side_route = ["红buff", "三猪", "蓝buff", "河道蟹"]
eff = route_efficiency(blue_side_route, 75)
print(f"蓝方标准路线效率: {eff:.1f} 经验/秒")
```

## P2 核心英雄池（第3-4周）

### 技能列表

- [英雄] `刺客打野精通（镜/澜/裴擒虎）—— 爆发连招、进场撤退时机`
- [英雄] `战士打野精通（赵云/铠/橘右京）—— 半肉切入、持续作战能力`
- [英雄] `蓝领打野理解（阿古朵/盘古）—— 让资源、保C位、控图型打法`
- [反野] `学习1级入侵的判断条件：双方阵容强度、中路是否有线权`

### 图解

```
打野英雄分类与选择逻辑：

        需要切C？────────→ [刺客系] 镜/澜/裴擒虎/娜可露露
         │                     高爆发、脆皮、依赖经济
         │
        需要前排+输出？─→ [战士系] 赵云/铠/橘右京/曜
         │                    半肉、持续作战、容错率高
         │
        阵容不缺输出？──→ [蓝领系] 阿古朵/盘古/猪八戒
                              让Buff、控图、团队型

Counter链示例（刺客打野）：
    裴擒虎 ←→ 镜：老虎前期入侵压制镜（1级强度碾压）
    镜    ←→ 澜：镜的镜像机制克制澜的突进
    澜    ←→ 露露：澜的机动性可规避露露的爆发期
```

### 代码

```python
# 英雄池熟练度追踪
hero_pool = {
    "镜":     {"type": "刺客", "games": 0, "wr": 0.0, "target_games": 50},
    "澜":     {"type": "刺客", "games": 0, "wr": 0.0, "target_games": 30},
    "赵云":   {"type": "战士", "games": 0, "wr": 0.0, "target_games": 40},
    "铠":     {"type": "战士", "games": 0, "wr": 0.0, "target_games": 30},
}

def hero_progress(hero_name):
    h = hero_pool[hero_name]
    pct = min(100, h["games"] / h["target_games"] * 100)
    return f"{hero_name} 熟练度: {pct:.0f}% ({h['games']}/{h['target_games']}场)"

for name in hero_pool:
    print(hero_progress(name))
```

- [视野] `蹲草卡视野技巧：利用草丛边缘的视野差制造"看不见的杀机"`
- [运营] `兵线处理与Gank时机联动：兵线到塔下再抓 → 最大化推塔收益`

### 图解

```
Gank优先级判定流程：

    观察小地图 →
    ├─ 敌方压线过河道？──→ 抓！(成功率>70%)
    ├─ 敌方残血在塔下？──→ 观察我方兵线位置
    │                        ├─ 兵线进塔 → 越塔
    │                        └─ 无兵线    → 放弃
    ├─ 双方和平发育？  ──→ 刷野/反蹲/拿龙
    └─ 敌方打野露出？──→ 判断位置
                             ├─ 远侧 → 入侵他的另一边野区
                             └─ 近侧 → 反蹲我方被压路线

资源优先级（按时间轴）：
    1:30 河道蟹 > 剩余小野 > Gank
    2:00 第一条龙 > 抓人 > 刷野
    4:00 防御塔护盾消失 → 推塔优先级↑
    10:00 黑暴/暗影主宰 → 决定中期节奏
    20:00 风暴龙王      → 决胜时刻
```

- [视野] `关键眼位布控：龙坑上方草丛、buff背后草丛、河道中央`
- [反野] `防守型反野：当队友被压制时，偷敌方另一侧野区止损`

### 图解

```
反野决策流程：

    判断敌方打野位置 →
    ├─ 敌打野在上路露头？──→ 入侵红区！
    │                          ├─ 红buff在？ → 偷红
    │                          └─ 红不在？  → 偷小野+做视野
    ├─ 敌打野位置未知？  ──→ 看Buff状态
    │                          ├─ 红/蓝buff刷新中 → 蹲草丛反蹲
    │                          └─ 无信息        → 正常发育
    └─ 我方正被入侵？    ──→ 信号集合队友
                               ├─ 人数优势 → 反杀
                               └─ 人数劣势 → 换野区止损

关键眼位（蓝方视角）：
            [龙坑上方草] ← 控制暴君区视野
           /
    ［河道中央］ ← 监控中路游走
           \
    ［红buff背后草］ ← 保护红区+抓到敌方偷红
```

- [BP] `Ban/Pick决策：看前三楼阵容→确定己方打野类型→Ban克制英雄`
- [节奏] `逆风局处理：避战发育→带线牵制→抓单→拖后期`

### 图解

```
BP阶段打野决策：

    看双方阵容 →
    ├─ 对面多脆皮（无前排）？→ 选刺客打野（镜/澜）
    ├─ 对面有保护体系？      → 选战士打野（铠/赵云）半肉切C
    ├─ 我方缺前排？          → 选蓝领打野（阿古朵）
    └─ 对面先选强势打野？   → Counter Pick
                               ├─ 对面选镜 → 选裴擒虎（前期压制）
                               ├─ 对面选澜 → 选镜（机制克制）
                               └─ 对面选铠 → 选盘古（缴械克制）

团战进场时机（刺客打野）：
    │ 等待 │────→ 观察敌方关键控制技能是否交出
    │      │        ├─ 张飞大招已交？ → 进入Stage 2
    │      │        └─ 控制还在？    → 继续等待
    │ 切入 │────→ 从侧翼/后方进场
    │      │        目标优先级：射手 > 法师 > 辅助
    │ 撤退 │────→ CD期拉出战场 → 等技能转好 → 再次进场
```

## P6 实战演练（第11-13周）

### 技能列表

- [全标签] `录像复盘：每日挑选2场对局 → 用"停·问·改"法分析`
- [全标签] `制定"专项训练模块"：逆风局特训、后期团战特训、视野布控特训`
- [全标签] `排位冲刺：连续15场同一英雄 → 建立肌肉记忆 → 统计胜率变化`
- [团战] `参团时机判断训练：统计5场排位中"成功团战"与"失误团战"的比例`

### 图解

```
录像复盘"停·问·改"法：

    观看录像 →
    │
    ├─ 【停】每2分钟暂停一次
    │   记录此时：你在哪？敌打野在哪？龙还有多久刷新？
    │
    ├─ 【问】对关键节点提出5个问题
    │   ① 这个时间点我为什么在这里？（Gank/刷野/拿龙/转线）
    │   ② 敌打野此时在做什么？我有没有考虑他的路线？
    │   ③ 这波Gank成功/失败的核心原因是什么？
    │   ④ 如果重来一次，我的最优选择是什么？
    │   ⑤ 这个决策影响了后续多少分钟的局势？
    │
    └─ 【改】提炼1-2条可立即执行的改进
         写下："下次XX情况下，我要XX而不是XX"
         放入训练待办清单
```

## 实操练习题库

### 初级练习题（第1-4周）

1. 默写王者峡谷的全部野怪位置、首次刷新时间、后续刷新间隔
2. 在训练营中完成裴擒虎/镜的1级红开→三猪→蓝→河道蟹路线，计时并记录到秒
3. 连续10场排位使用同一个打野英雄，记录每场的Gank次数、成功率、对位打野的路线
4. 画出蓝方和红方各3种标准开局路线（红开/蓝开/入侵）
5. 观看1场KPL比赛回放，追踪双方打野的每分钟位置并画出轨迹图

### 中级练习题（第5-8周）

6. 对10场排位进行"假视野"技术测试：至少3次故意暴露→反向移动→记录敌方反应
7. 设计一份"反野时机检查表"：列出己方入侵前必须确认的3个条件，并在5场排位中严格执行
8. 统计20场排位中"第一条龙的控制率"与胜率的关系（你和敌方打野各拿了几条）
9. 选择一名你准备精通的打野英雄，写出完整的3级/4级/6级连招伤害计算
10. 在不同对局中记录敌方打野的常用开局路线，连续10场后总结出你所处分段打野的习惯模式
11. 针对镜/澜/裴擒虎各写出1份CounterPick方案（用什么英雄克制、用什么策略应对）
12. 在5场排位中仅凭小地图信息（不切屏看具体位置）推断敌方打野位置，赛后看录像验证准确率

### 高级练习题（第9-13周）

13. 选取3场败局录像，用"停·问·改"法进行完整复盘，输出至少2000字的复盘报告
14. 冲刺同一英雄连续20场排位：前10场和后10场的胜率/KDA/Gank成功率对比分析
15. 设计3套不同的"4级后节奏路线"（抓中压塔型/入侵反野型/控龙发育型），各测试5场
16. 制定BP阶段的"Ban/Pick决策模板"：根据我方1-2楼选人→确定打野选择范围→Ban克制英雄
17. 分析S35赛季打野T0/T1英雄的胜率/出场率/Ban率数据，推断版本核心打法（控龙/入侵/发育）
18. 收集5场"被压制/崩盘"局的数据：在被压的情况下你的Gank成功率/经济占比变化曲线

### 大作业（第14-15周）

19. **【大作业】打野位综合能力评估**：Self-review 200场排位数据 → 雷达图评估（刷野效率/Gank成功率/资源控制/团战表现/KDA/经济转化）→ 制定下赛季目标
20. **【大作业】教学输出**：撰写1篇万字打野入门教程帖（配GIF动图/小地图标注）→ 发布至NGA/B站 → 收集反馈并迭代
21. **【大作业】英雄池扩展计划**：在当前英雄池基础上新增2名打野英雄 → 制定"50场入门→100场精通"的练习计划 → 追踪胜率提升曲线

## 学习进度检查清单

### ☐ P1 打野基础认知（第1-2周）
- [ ] 能准确说出每个野怪的刷新时间和经验值
- [ ] 完成3种标准开局路线的训练营计时
- [ ] 在排位中连续10场没有"忘记河道蟹"的情况
- [ ] 看完至少2场KPL打野第一视角的完整回放

### ☐ P2 核心英雄池（第3-4周）
- [ ] 确定主练英雄（刺客类至少1名）
- [ ] 主练英雄完成30场排位（胜率记录）
- [ ] 副练英雄（战士/蓝领类至少1名）完成15场
- [ ] 至少写出主练英雄的3套连招+出装顺序

### ☐ P3 节奏运营（第5-6周）
- [ ] 根据"Gank优先级流程"完成每局的Gank决策记录
- [ ] 连续10场排位中"无效Gank"（人没抓到→没推塔→没反野→自己掉了发育）<20%
- [ ] 每局比赛至少做到2次"兵线到塔→接着Gank→推塔"的完整节奏链

### ☐ P4 进阶策略（第7-8周）
- [ ] 每局比赛至少有1次"基于信息差"的入侵/反蹲
- [ ] 龙坑上方草丛眼位布控率>50%（局内查看）
- [ ] 支配/暴君的参与击杀率>60%（你和你的队友）

### ☐ P5 高端局节奏（第9-10周）
- [ ] 团战前确保至少1条兵线推到河道
- [ ] 每局BP阶段有明确的"打野选择+Ban英雄"方案
- [ ] 逆风局中打野经济不低于全队平均（衡量你的抗压刷野能力）

### ☐ P6 实战演练（第11-13周）
- [ ] 完成10场完整录像复盘（停·问·改流程）
- [ ] 单一英雄场次>50场，熟练度指标达到预期
- [ ] 专项训练（逆风/团战/视野）各完成5场针对性练习

### ☐ P7 综合提升（第14-15周）
- [ ] 提交1份赛季总结报告（包括英雄池数据、胜率趋势、提升方向）
- [ ] 完成至少1篇教学帖/1个教学视频
- [ ] 设定达成或接近赛季目标分数
- [ ] 确定下赛季的主练方向和英雄优先级
