## 总体学习路线图

### 🎯 学习目标

1. 掌握A股市场的基础运作机制——从开户到完成第一笔实盘交易的全流程
2. 熟练使用至少3种技术指标（MA/MACD/KDJ/RSI）进行买卖点判断，并能看懂K线形态语言
3. 学会使用基本面分析筛选股票——PE/ROE/行业景气度的三角评估框架
4. 建立完整的风险控制体系：仓位管理→止损止盈→最大回撤控制→资金曲线管理
5. 形成可复制的个人交易系统：选股→择时→进场→持仓→出场→复盘→迭代

### 🧭 核心理念

> **“炒股的本质不是预测涨跌，而是管理风险与概率”**
> — 没有人能100%预测方向，但每个人都可以控制亏损的幅度和交易的频率

> **“市场永远是对的，错的只能是你自己”**
> — 亏损的第一反应不是找理由（庄家/政策/黑天鹅），而是检查：我违反了哪条交易纪律？

> **“慢就是快——复利是世界第八大奇迹”**
> — 每月稳定盈利5%，一年=1.8倍，两年=3.2倍。追求单月翻倍的代价往往是清零

## 图解学习法

### 为什么炒股需要图解学习？

炒股本质是**图形识别 + 概率决策**——K线图、分时图、趋势线、成交量柱状图，这些视觉信息远超文字描述的密度。画图能帮助你在大脑中建立“图形→机会/风险”的直觉映射（即盘感）。

### 三步法

| 步骤 | 方法 | 炒股示例 |
|------|------|---------|
| **抄图** | 对着行情软件手绘K线形态、均线排列、MACD走势 | 画出“底背离→金叉确认”的标准买入信号组合 |
| **默图** | 不看参考，凭记忆还原关键形态和信号 | 默画“头肩顶”形态的6个关键要素（左肩/头/右肩/颈线/量能/目标位） |
| **讲图** | 向自己/他人讲解图中每一个信号的逻辑 | “为什么这根放量阳线确认了支撑有效而不是诱多？” |

### 画图层级

- **[必画]** — K线基础形态（12种）、均线多空排列（3种）、MACD背离与金叉死叉（4种）、经典反转形态（6种）、止损止盈位置示意图
- **[建议画]** — 仓位管理金字塔图、行业轮动周期图、个人交易流程图（选股→进场→持仓→出场）
- **[可选画]** — 龙虎榜游资行为分析图、板块资金流示意图、宏观经济指标传导链

### 推荐视觉资源

- 同花顺/东方财富App → K线训练营功能（匿名历史K线→预测后续走势→即时反馈）
- TradingView → 丰富的画图工具和指标叠加
- 东方财富网 → 龙虎榜可视化、资金流向热力图

## P2 K线与技术指标（第3-4周）

### 技能列表

- `[技术]` K线基础：阳线/阴线/十字星/锤子线/倒锤子/吞没形态
- `[技术]` 均线系统(MA)：5/10/20/60/120/250日均线的含义与用法
- `[技术]` MACD指标：DIF/DEA线、金叉死叉、顶底背离
- `[技术]` RSI指标：超买(>70)/超卖(<30)区域判断
- `[技术]` KDJ指标：K/D/J三线关系、超买超卖
- `[技术]` BOLL布林带：上中下轨含义、开口收口信号
- `[实战]` 多指标组合验证：至少2个指标共振才入场

### 核心概念

```
均线多空排列：
多头排列（上升趋势）：
    MA5  ↑
    MA10 ↑  短期在上
    MA20 ↑
    MA60 ↑  长期在下
    ——→ 上升通道打开

空头排列（下降趋势）：
    MA60 ↓
    MA20 ↓  长期在上
    MA10 ↓
    MA5  ↓  短期在下
    ——→ 下降通道确认

金叉/死叉：
金叉：短期均线上穿长期均线 → 买入信号
死叉：短期均线下穿长期均线 → 卖出信号
```

```
MACD背离信号：
顶背离：股价新高 + MACD未新高 → 见顶预警
   股价：  ↗ ↗ ↗
   MACD： → → →
   ——→ 卖点临近！

底背离：股价新低 + MACD未新低 → 见底预警
   股价：  ↘ ↘ ↘
   MACD： → → →
   ——→ 买点临近！
```

```
BOLL布林带信号：
┌─────────────────────────┐
│ 上轨（压力位）           │ ← 股价触及上轨=短线超买
│     价格运行区间        │
│ 中轨（20日均线）         │ ← 趋势方向核心参考
│                        │
│ 下轨（支撑位）           │ ← 股价触及下轨=短线超卖
└─────────────────────────┘

开口放大 = 趋势加速（上车或止损）
开口收窄 = 变盘前兆（耐心等待方向选择）
```

## P3 选股与基本面分析（第5-6周）

### 技能列表

- `[基本面]` 财务三表入门：资产负债表/利润表/现金流量表阅读方法
- `[基本面]` 核心估值指标：PE(市盈率)/PB(市净率)/ROE(净资产收益率)
- `[基本面]` PEG估值法：PEG=PE/净利润增长率，PEG<1=低估
- `[基本面]` 行业分析：赛道选择/景气周期/政策导向
- `[基本面]` 股东研究：十大股东/机构持仓/北向资金
- `[实战]` 同花顺iFinD/东方财富Choice数据查询实战

### 核心概念

```
选股三角评估框架：
          PE/PB/ROE
          (估值维度)
           /     \
          /       \
         /   选股   \
        /   决策     \
       /             \
  行业景气度 ──────── 技术面信号
 (赛道维度)          (择时维度)

三角共振=高确定性机会
单边驱动=需降低仓位
```

```
财务三表核心指标速览：
资产负债表：
  [基础] 总资产 = 负债 + 所有者权益
  [基础] 资产负债率↓ = 财务更健康
  [基本面] 货币资金/短期借款 → 现金流安全性

利润表：
  [基础] 营业收入增长率↑ = 业务扩张
  [基础] 净利润率↑ = 盈利能力提升
  [基本面] 扣非净利润 vs 净利润 → 剔除一次性收益

现金流量表：
  [基础] 经营现金流净额>0 = 造血功能正常
  [基本面] 经营现金流/净利润>1 = 利润含金量高
```

```
PE估值区间参考（不同行业不同标准）：
消费品龙头(茅台)：PE 25-35 = 合理
科技成长股(半导体)：PE 40-80 = 合理
银行股：PE 5-10 = 合理
周期股(钢铁/化工)：PE 10-20 = 合理
——关键是：PE低于历史中位数+PEG<1+行业景气向上
```

## P5 资金管理与风控体系（第9-10周）

### 技能列表

- `[风控]` 仓位管理：单票仓位上限（≤20%）/总仓位控制/金字塔加仓法
- `[风控]` 止损策略：固定比例止损(-5%/-8%)/移动止盈/技术位止损
- `[风控]` 风险收益比(R/R)：进场前计算止盈空间/止损空间≥2:1
- `[风控]` 凯利公式入门：最优仓位 = (胜率×盈亏比-败率)/盈亏比
- `[风控]` 最大回撤控制：账户总回撤>10%=暂停交易一周
- `[心理]` 盈亏心态管理：截断亏损→让利润奔跑→接受小亏是交易成本

### 核心概念

```
仓位管理金字塔：
         ┌──────┐
         │ 追涨  │ 5%仓位（确定性低）
         │ 仓位  │
       ┌─┴──────┴─┐
       │  确认加仓 │ 10%仓位（趋势确认后）
       │  仓  位   │
     ┌─┴──────────┴─┐
     │   初始建仓    │ 5-10%仓位（试仓阶段）
     │   试  仓      │
     └──────────────┘

总仓位纪律：
牛市(上升趋势)：50%-80%仓位
震荡市(横盘)：30%-50%仓位
熊市(下降趋势)：0%-20%仓位或空仓
```

```
止损三件套：
1. 固定比例止损
   买入价的-5% ~ -8%
   → 触发立即卖出，不找理由

2. 移动止盈（保护利润）
   股价上涨10% → 止损线上移至成本价
   股价上涨20% → 止损线上移至+10%
   股价上涨30% → 止损线上移至+20%
   → 不卖在最高点，但锁定盈利

3. 技术位止损
   买入逻辑被破坏即止损
   如：跌破支撑位/跌破重要均线/破位颈线
```

```
风险收益比(R/R)计算：
买入价：10.00
止损价：9.50  → 风险 = 0.50  (5%)
目标价：11.00 → 收益 = 1.00 (10%)
R/R = 1.00/0.50 = 2:1 ✓

铁律：R/R < 2:1 的交易不做！
即使胜率只有40%：
40%×2R - 60%×1R = 0.8R - 0.6R = +0.2R（正期望！）
```

## P6 实战模拟与实盘操作（第11-13周）

### 技能列表

- `[实战]` 模拟盘训练：同花顺模拟炒股/东方财富模拟盘 至少100笔交易
- `[实战]` 实盘小资金入场：初始资金≤1万元→验证交易系统
- `[实战]` 每日复盘流程：当天操作回顾→对错分析→明日计划
- `[实战]` 交易日志模板（必写！）：日期/代码/方向/价位/仓位/理由/结果/反思
- `[实战]` 选股实战全流程：大盘判断→板块选择→个股筛选→等待买点→执行→记录
- `[实战]` 看盘时间管理：早盘9:15-10:00(最活跃)/尾盘14:30-15:00(收盘博弈)

### 核心概念

```
完整交易流程：
┌─────────────────────────────────────┐
│ 1. 大盘环境判断（做不做？）          │
│    上证/创业板趋势↑？成交量>万亿？   │
├─────────────────────────────────────┤
│ 2. 板块/热点选择（做什么方向？）    │
│    当日涨停最多板块→龙头是谁？       │
├─────────────────────────────────────┤
│ 3. 个股筛选（做哪只？）               │
│    板块龙头+技术形态+量价配合         │
├─────────────────────────────────────┤
│ 4. 等待进场信号（什么时候做？）      │
│    MACD金叉+放量突破+回踩不破        │
├─────────────────────────────────────┤
│ 5. 执行交易（开盘操作）              │
│    挂单→成交→设止损→记录交易日志     │
├─────────────────────────────────────┤
│ 6. 持仓管理（持仓中）                 │
│    跟踪止损上移/关注大盘/板块热度     │
├─────────────────────────────────────┤
│ 7. 出场（止盈/止损）                 │
│    触发条件立即执行→记录→复盘         │
└─────────────────────────────────────┘
```

## 核心公式与概念速查表

### Table 1: K线与均线

| 概念 | 公式/数值 | 说明 |
|------|----------|------|
| MA(n) | `(P₁+P₂+...+Pₙ)/n` | n日收盘价的简单移动平均 |
| 金叉 | `MA(短)上穿MA(长)` | 短期均线上穿长期均线=买入信号 |
| 死叉 | `MA(短)下穿MA(长)` | 短期均线下穿长期均线=卖出信号 |
| 多头排列 | `MA5>MA10>MA20>MA60` | 均线从上到下由短到长排列 |
| 空头排列 | `MA60>MA20>MA10>MA5` | 均线从上到下由长到短排列 |

### Table 2: 技术指标

| 概念 | 公式/数值 | 说明 |
|------|----------|------|
| MACD金叉 | `DIF上穿DEA` | 快线上穿慢线=买入信号 |
| MACD死叉 | `DIF下穿DEA` | 快线下穿慢线=卖出信号 |
| RSI超买 | `RSI(14)>70` | 高位风险区，警惕回调 |
| RSI超卖 | `RSI(14)<30` | 低位区域，关注反弹 |
| KDJ金叉 | `K线上穿D线` | 短线买入信号（需配合趋势） |
| BOLL开口 | `上轨-下轨扩大` | 波动率上升=趋势加速 |

### Table 3: 估值指标

| 概念 | 公式/数值 | 说明 |
|------|----------|------|
| PE(市盈率) | `股价/每股收益` | 静态PE用去年EPS，动态PE用预期EPS |
| PB(市净率) | `股价/每股净资产` | 银行/保险/钢铁行业更看重PB |
| ROE(净资产收益率) | `净利润/净资产×100%` | ROE>15%=优秀，持续>20%=卓越 |
| PEG | `PE/净利润增长率(%)` | PEG<1=低估，1-2=合理，>2=高估 |
| 股息率 | `每股分红/股价×100%` | 稳定高股息适合长期持有 |

### Table 4: 风控参数

| 概念 | 公式/数值 | 说明 |
|------|----------|------|
| 单笔风险上限 | `≤总资金的1-2%` | 每笔交易最大可承受亏损 |
| 风险收益比(R/R) | `(目标价-买入价)/(买入价-止损价)` | 必须≥2:1才进场 |
| 凯利公式 | `f=(p×b-q)/b` | p=胜率 b=盈亏比 q=败率(1-p) |
| 最大回撤MDD | `(峰值-谷值)/峰值×100%` | 超过10%=暂停交易 |
| 期望值 | `胜率×平均盈利-败率×平均亏损` | 必须为正，否则系统有漏洞 |

### Table 5: 经典形态量度

| 概念 | 公式/数值 | 说明 |
|------|----------|------|
| 头肩顶目标位 | `颈线-(头部-颈线)` | 跌破颈线后的最小跌幅 |
| W底目标位 | `颈线+(颈线-底部)` | 突破颈线后的最小涨幅 |
| 三角形突破目标 | `突破点±三角形最大宽度` | 向上/向下三角形的量度升跌幅 |
| 通道交易 | `买入:下轨+确认信号/卖出:上轨+确认信号` | 震荡市通道内高抛低吸 |
| 旗形目标 | `旗杆长度+突破点` | 旗形整理后的延续目标位 |

## 实操练习题库

### 初级练习题（第1-4周）

1. 打开同花顺或东方财富App，完成开户→银证转账→用1手(100股)完成第一笔真实买入，记录全过程时间
2. 随机抽取50根历史K线，逐根标注：阳线/阴线/十字星/锤子线，正确率目标>90%
3. 在任意股票日K线图上画出MA5/MA10/MA20/MA60四条均线，找出最近一次金叉和死叉
4. 选择5只股票，查看它们的MACD指标，判断当前处于金叉状态还是死叉状态
5. 在模拟盘中用均线金叉+MACD金叉双指标条件，完成10笔模拟买入→跟踪3天→记录结果

### 中级练习题（第3-8周）

6. 选取10只不同行业的股票，查它们的PE/PB/ROE数据，按PE从低到高排序分析估值水平
7. 在任意股票日K线图上找出一个头肩顶形态和一个W底形态，标注颈线和目标位
8. 用BOLL布林带分析一只股票过去3个月的走势：标注开口收口位置和对应的股价方向
9. 在模拟盘中用“底部放量突破+MACD金叉”策略交易20笔，统计胜率和盈亏比
10. 找一只股票，画出其过去6个月的趋势线和通道，标注支撑位和阻力位
11. 选取3只股票，分析它们最新一期的资产负债表：计算资产负债率/流动比率
12. 用东方财富网查5只股票的研报评级和目标价，与实际价格对比分析

### 高级练习题（第7-12周）

13. 设计自己的选股checklist（至少包含：估值/成长性/技术面/资金面 4个维度共10条标准），用这套标准筛选10只股票
14. 在模拟盘中严格执行止损纪律：连续20笔交易，每笔都预设止损位，统计止损触发次数和执行率
15. 做一次完整的“买入→持仓→止盈”全流程：从选股开始→等待买点→进场→设止损→移动止盈→出场→写复盘日志
16. 统计过去一个月所有交易的盈亏比和胜率，计算期望值E = 胜率×平均盈利-败率×平均亏损
17. 分析一只股票过去一年的所有涨停日期，找涨停前的共同特征（板前均线/MACD/量能状态）
18. 做一次“连亏3笔后停止交易”的纪律训练——连亏3笔后至少2天不交易→写反思日志

### 大作业（第10-15周）

19. **【大作业】** 构建完整的个人交易系统文档：包含选股规则/进场条件/仓位管理/出场规则/风控参数，用历史数据手动回测至少30笔
20. **【大作业】** 连续30天每日复盘日志：每天记录 ①当天操作 ②大盘与板块判断 ③对错分析 ④明日计划 ⑤心态记录
21. **【大作业】** 模拟盘完成100笔有记录的交易→统计胜率/盈亏比/最大回撤/月收益率→写一份完整的交易总结报告
