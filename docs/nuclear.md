## 一、总体学习路线图

### 学习目标
能够系统掌握核物理的核心理论与应用：
- 理解原子核的结构、稳定性和衰变机制
- 掌握核反应的基本原理和计算
- 了解核能、核医学、辐射防护等应用
- 具备阅读核物理前沿论文的能力
- 能够独立完成核物理相关的基础计算和实验设计

### 核心理念

> **"核物理不是魔法，是量子多体问题的自然延伸"**——原子核由最多不过数百个核子组成，但其行为却极其丰富。理解核物理的关键在于：量子力学+强相互作用+多体物理。

> **"一张图抵过千行公式"**——核物理的许多概念（能级结构、衰变链、反应截面、壳层填充）本质上是几何的、可视的。本方案在每个关键概念处都配有图示指南。

> **"数学是物理的语言，实验是物理的裁判"**——核物理的每一个公式都对应一个可测量的物理量。本方案在公式旁标注对应的实验测量方法。

### 2.6 本阶段代码实操

```python
# 核素图与结合能曲线绘制
import numpy as np
import matplotlib.pyplot as plt

# Weizsacker 半经验质量公式（预览，第三阶段详解）
def binding_energy_per_nucleon(A, Z):
    a_v, a_s, a_c, a_a, a_p = 15.75, 17.8, 0.711, 23.7, 11.18
    N = A - Z
    delta = a_p / np.sqrt(A) if A % 2 == 0 and Z % 2 == 0 else \
            -a_p / np.sqrt(A) if A % 2 == 0 else 0
    B = (a_v*A - a_s*A**(2/3) - a_c*Z*(Z-1)/A**(1/3)
         - a_a*(N-Z)**2/A + delta)
    return B / A

# 绘制稳定核素图
As = np.arange(1, 260)
stable_Z = []
for A in As:
    Z_range = np.arange(max(1, int(A/3)), min(A, int(2*A/3)) + 1)
    BE = [binding_energy_per_nucleon(A, Z) for Z in Z_range]
    stable_Z.append(Z_range[np.argmax(BE)])

plt.plot(np.array(stable_Z), As - np.array(stable_Z), 'k-', lw=1.5)
plt.xlabel('Z (质子数)')
plt.ylabel('N (中子数)')
plt.title('β稳定线（理论计算）')
plt.grid(alpha=0.3)
plt.show()
```

## 三、第二阶段：核模型与结构

### 第3-4周 学习内容

### 3.1 液滴模型——理解裂变的钥匙 [多体]

#### 物理思想
将原子核看作一个带电的不可压缩液滴：
- 核子间的短程吸引力 → 液滴的表面张力
- 质子间的长程库仑力 → 液滴带正电荷
- 核密度近似常数 → 液滴不可压缩

#### Weizsacker 半经验质量公式 [数学]

```
B(Z,A) = a_v·A - a_s·A^(2/3) - a_c·Z(Z-1)/A^(1/3)
         - a_a·(N-Z)²/A + δ(A,Z)

五项物理含义（按顺序）：
① a_v·A              体积能 —— 核子数越多越稳定（强相互作用短程序）
② -a_s·A^(2/3)       表面能 —— 表面核子缺少邻居（类比水面张力）
③ -a_c·Z(Z-1)/A^(1/3) 库仑能 —— 质子间静电排斥（破坏稳定性）
④ -a_a·(N-Z)²/A      非对称能 —— 偏离 N=Z 需要能量（泡利不相容！）
⑤ ±δ(A,Z)            对能 —— 核子成对更稳定（超导的核物理版！）

推荐参数（MeV）：a_v=15.75, a_s=17.8, a_c=0.711, a_a=23.7, a_p=11.18
```

### 3.2 壳模型——核物理的"标准模型" [量子][群论]

#### 核心物理思想
核子在核内的运动不是无规则的——它们在**平均场势**中运动，填入量子化的能级，正如电子在原子的壳层结构中一样。

#### 幻数——核物理的"魔法数字"

```
魔数：2, 8, 20, 28, 50, 82, 126

幻数核的"超能力"：
- 特别稳定（结合能异常大）
- 自然界丰度异常高（⁴He, ¹⁶O, ⁴⁰Ca, ²⁰⁸Pb）
- 第一激发态能量异常高（难以激发）
- 电四极矩为零（球形）

²⁰⁸Pb 是唯一的双幻数稳定核：Z=82, N=126
```

#### 为什么是这些数字？——自旋-轨道耦合的魔法 [量子]

```

               1g(7/2)
```

```python
# Weizsacker公式可视化
import numpy as np
import matplotlib.pyplot as plt

def weizsacker(A, Z):
    a_v, a_s, a_c, a_a, a_p = 15.75, 17.8, 0.711, 23.7, 11.18
    N = A - Z
    delta = 0
    if A % 2 == 0:
        if Z % 2 == 0: delta = a_p / np.sqrt(A)
        else: delta = -a_p / np.sqrt(A)
    B = a_v*A - a_s*A**(2/3) - a_c*Z*(Z-1)/A**(1/3) - a_a*(N-Z)**2/A + delta
    return B/A

# 绘制结合能曲面
As = np.arange(4, 260, 2)
Zs = np.arange(1, max(As))
BE_grid = np.zeros((len(As), len(Zs)))
for i, A in enumerate(As):
    for j, Z in enumerate(Zs):
        if Z <= A:
            BE_grid[i, j] = weizsacker(A, Z)

plt.figure(figsize=(12, 6))
plt.contourf(Zs, As, BE_grid, levels=50, cmap='plasma')
plt.colorbar(label='B/A (MeV)')
plt.xlabel('Z')
plt.ylabel('A')
plt.title('结合能每核子 (Weizsacker公式)')
plt.show()
```

```python
# 衰变模拟与衰变链绘制
import numpy as np
import matplotlib.pyplot as plt

def decay_sim(N0, half_lives, t_max, dt):
    """模拟衰变链：母核→子核→孙核"""
    lambdas = np.log(2) / np.array(half_lives)
    N = np.zeros((len(t_max), len(lambdas)))
    N[0, 0] = N0
    for i in range(1, len(t_max)):
        N[i] = N[i-1]
        for j in range(len(lambdas)):
            N[i, j] -= lambdas[j] * N[i-1, j] * dt
            if j > 0:
                N[i, j] += lambdas[j-1] * N[i-1, j-1] * dt
    return N

# 铀系简化模拟 (选取关键核素)
hl = [4.47e9, 24.1/365/24, 1600]  # ²³⁸U, ²³⁴Th, ²²⁶Ra (年)
t = np.arange(0, 20000, 10)
dt = t[1] - t[0]
result = decay_sim(1000, hl, t, dt)

plt.figure(figsize=(10, 6))
labels = ['²³⁸U', '²³⁴Th (短命)', '²²⁶Ra']
for i in range(3):
    plt.plot(t, result[:, i], label=labels[i], lw=2)
plt.xlabel('时间 (年)')
plt.ylabel('核数')
plt.legend()
plt.grid(alpha=0.3)
plt.title('简化铀系衰变链')
plt.show()
```

### 5.1 核反应的基本描述 [散射]

#### 反应道与守恒律

```
反应：a + A → B + b  （或写作 A(a,b)B）

第一步：入射粒子 a 与靶核 A 发生作用
第二步：剩余核 B 处于特定状态 + 出射粒子 b

守恒律：
① 总电荷守恒：Z_a + Z_A = Z_B + Z_b
② 总核子数守恒（非相对论能区）
③ 总能量守恒：E_a + m_ac² = E_B + E_b + m_Bc² + m_bc²
④ 总动量守恒
⑤ 总角动量守恒
```

#### Q 值——反应的热力学

```
Q = (m_a + m_A - m_B - m_b)c²
  = (初始总质量 - 末态总质量)c²

Q > 0：放热反应——即使在零动能下也能发生
Q < 0：吸热反应——需要入射粒子有足够动能
       阈能 E_th = -Q · (m_a + m_A)/m_A   [质心修正]

实例：
  d + d → ³He + n       Q = +3.27 MeV  (放热)
  d + d → t + p          Q = +4.03 MeV  (放热)
  p + ⁷Li → ⁴He + ⁴He   Q = +17.35 MeV (大量放热！)
```

### 5.7 本阶段代码实操

```python
# 聚变截面计算与Lawson判据
import numpy as np
import matplotlib.pyplot as plt

def lawson_criterion(T_keV):
    """Lawson判据：n·τ_E 的最小值 (m⁻³·s)"""
    # d+t 反应的近似截面参数化
    if T_keV < 1: return float('inf')
    sigma_v = 3.68e-22 * np.exp(-19.94 / T_keV**(1/3)) * T_keV**(-2/3)
    # 简化：Bremsstrahlung + 回旋辐射损失
    P_loss = 5.35e-37 * np.sqrt(T_keV)
    P_fusion = sigma_v * 17.6e6 * 1.6e-19 / 4  # 4: α粒子能量份额
    Q = P_fusion / (P_loss - P_fusion * 0.8) if P_loss > P_fusion * 0.8 else float('inf')
    return Q

T_range = np.logspace(0, 2, 100)
Q_values = [lawson_criterion(T) for T in T_range]

plt.figure(figsize=(10, 6))
plt.semilogx(T_range, Q_values, 'b-', lw=2)
plt.axhline(y=1, color='r', linestyle='--', label='盈亏平衡 Q=1')
plt.axhline(y=10, color='g', linestyle='--', label='ITER目标 Q=10')
plt.axvline(x=10, color='gray', alpha=0.5, label='典型温度 10 keV')
plt.xlabel('温度 T (keV)')
plt.ylabel('能量增益因子 Q')
plt.title('Lawson判据：d+t 聚变能量增益')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

```python
# γ能谱峰拟合示例
import numpy as np
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

def gauss_plus_linear(x, A, mu, sigma, a, b):
    return A * np.exp(-(x-mu)**2 / (2*sigma**2)) + a*x + b

# 模拟数据：⁶⁰Co 的两个峰 + 小本底
x = np.linspace(1100, 1400, 300)
y = (1000*np.exp(-(x-1173)**2/10) +
     1000*np.exp(-(x-1332)**2/10) +
     0.05*x + 50 +
     np.random.normal(0, 5, 300))

popt, _ = curve_fit(gauss_plus_linear, x, y,
                     p0=[1000, 1173, 3, 0.05, 50])

plt.figure(figsize=(10, 5))
plt.plot(x, y, 'k.', ms=2, alpha=0.5, label='数据')
plt.plot(x, gauss_plus_linear(x, *popt), 'r-', lw=1.5, label='拟合')
plt.axvline(popt[1], color='blue', ls='--', label=f'峰1: {popt[1]:.1f} keV')
plt.axvline(popt[1]+popt[4]*6, color='green', ls='--')
plt.xlabel('能量 (keV)')
plt.ylabel('计数')
plt.title('⁶⁰Co γ能谱峰拟合')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

## 十、核心公式与概念速查表

### 10.1 结合能与质量公式 `[多体][数学]`

| 公式 | 名称 | 物理含义 |
|------|------|----------|
| B(Z,A) = [Z·m_p + N·m_n - m(Z,A)]·c² | 结合能定义 | 把核拆成自由核子需要的能量 |
| B/A ≈ 8 MeV (A≥20) | 每核子平均结合能 | **铁峰**在 A≈56 |
| B = a_v·A - a_s·A^(2/3) - a_c·Z(Z-1)/A^(1/3) - a_a·(N-Z)²/A ± δ | Weizsacker 公式 | 五项物理贡献 |
| R = r₀·A^(1/3), r₀ ≈ 1.2 fm | 核半径 | 液滴模型的基本假设 |

### 10.2 放射性衰变 `[统计][量子]`

| 公式 | 名称 | 物理含义 |
|------|------|----------|
| dN/dt = -λN | 衰变定律 | 每个核衰变概率不变 |
| N(t) = N₀·e^(-λt) | 指数衰变 | 群体行为 |
| T_1/2 = ln(2)/λ | 半衰期 | 剩下一半需要的时间 |
| A = λN | 活度 | 每秒衰变数 |
| ln λ = a - b/√Q_α | Geiger-Nuttall | α 衰变能-寿命关系 |
| P_tunnel ≈ exp(-2G) | Gamow 隧穿概率 | 量子隧穿 |

### 10.3 核反应 `[散射]`

| 公式 | 名称 | 物理含义 |
|------|------|----------|
| dσ/dΩ = |f(θ)|² | 微分截面（弹性散射） | 
| σ ∝ 1/v (低能中子) | 1/v 律 | 越慢越容易反应 |
| σ_nf ≈ 585 barns (²³⁵U, 热中子) | 裂变截面 | 核能工程的基石 |

### 10.4 选择定则与守恒律 `[群论]`

| 条件 | 适用范围 | 说明 |
|------|----------|------|
| ΔJ = 0, ±1 (不含0→0), Δπ = + | 允许 β 跃迁 (F/GT) | 上下夸克翻转 |
| ΔJ = L, Δπ = (-1)^L (E) | γ 电多极辐射 | 光子带走角动量 L |
| ΔJ = L, Δπ = (-1)^(L+1) (M) | γ 磁多极辐射 | |
| J^P = 0⁺ (所有偶偶核基态) | 核子配对 | 对关联的杰作 |

### 10.5 标准模型 `[群论]`

| 公式/概念 | 说明 |
|-----------|------|
| SU(3)_C × SU(2)_L × U(1)_Y | 标准模型规范群 |
| 夸克 = 3 种色 (SU(3)_C) | 每种味有 3 种色荷 |
