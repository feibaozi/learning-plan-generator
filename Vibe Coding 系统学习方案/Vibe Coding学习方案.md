## 项目驱动学习法

本方案基于 G8（教程实操型）纹理，核心方法论是 **项目驱动学习** —— 不同于传统的"先学理论再实践"，vibe coding 的最佳学习路径是：

```ascii
      ┌──────────────┐
      │  1. 选定项目   │ ← 找一个你想做的真实项目
      └──────┬───────┘
             ▼
      ┌──────────────┐
      │  2. AI辅助开发  │ ← 用AI工具开始写第一行代码
      └──────┬───────┘
             ▼
      ┌──────────────┐
      │  3. 遇到问题   │ ← 调试、理解AI生成的代码
      └──────┬───────┘
             ▼
      ┌──────────────┐
      │  4. 回补知识   │ ← 为解决问题而学习原理
      └──────┬───────┘
             ▼
      ┌──────────────┐
      │  5. 迭代优化   │ ← 用新知识改进代码和流程
      └──────────────┘
```

**关键原则**：
- **先跑起来再说**：不要追求第一次就写出完美的 prompt 或代码
- **每个阶段有产出**：让每个阶段结束时都有可在 GitHub 上展示的项目
- **AI是你的结对编程伙伴**：遇到问题先问 AI，再查文档，最后看原理
- **记录你的提示词库**：积累一套你自己的高效 prompt 模板

## 核心公式与概念速查表

| 名称 | 概念/公式 |
|------|----------|
| 提示词效率公式 | 效果 = 任务清晰度 × 上下文丰富度 × 约束明确度 |
| Token 消耗估算 | 代码 token ≈ 字符数 × 0.25 ~ 0.33（英文），× 0.5 ~ 0.7（中文） |
| AI编程时间节省率 | 节省率 = (传统开发时间 - AI辅助开发时间) / 传统开发时间 × 100% |
| Agent决策周期 | 决策循环 = 感知 → 规划 → 执行 → 验证 → 感知... |

## 实操练习题库

### 🟢 基础练习（3题）

1. **搭建你的第一个AI编程环境** — 安装并配置 Cursor 或 Windsurf，连接 API Key，完成第一个 AI 辅助的 "Hello World" 程序
2. **编写基础代码生成提示词** — 针对一个简单功能（如文件读写、HTTP请求），写出 3 个不同详细程度的提示词并对比 AI 输出质量
3. **使用 AI 分析陌生代码库** — 在 GitHub 上找一个陌生的小型开源项目，使用 AI 工具在 30 分钟内理解其架构

### 🟡 进阶练习（4题）

4. **AI 辅助开发一个 CRUD Todo 应用** — 使用 AI 从头构建一个完整的 Todo 应用（前端 + 后端 + 数据库），记录完整的 prompt 历史
5. **使用 AI 定位并修复一个 Bug** — 在一个有已知 Bug 的项目中，用 AI 工具完成"定位 → 分析 → 修复 → 验证"全流程
6. **AI 生成单元测试** — 为一个已有模块编写完整的测试用例，通过 AI 生成测试代码，确保覆盖率达到 80%+
7. **对比两个不同 AI 工具的效率** — 用 Cursor 和 GitHub Copilot 分别完成相同任务，记录时间、代码质量、提示词效率

### 🔴 挑战练习（2题）

8. **AI 辅助重构遗留代码** — 找一段质量较差的遗留代码，使用 AI 工具完成重构（提取函数、改进命名、添加类型注解）
9. **设计一个多模型协作工作流** — 设计一个需要 Claude（编码）+ GPT-4（创意）+ 本地模型（轻量任务）协作的场景，实现端到端工作流

### 📦 项目练习（1题）

10. **从零构建并部署一个个人网站** — 使用 AI 工具全流程完成：需求分析 → UI 设计 → 前端开发 → 后端 API → 数据库 → 部署上线，全程由 AI 辅助，记录完整学习笔记
